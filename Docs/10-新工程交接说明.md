## asmdef 策略（对方案 §15 的落地简化）

**只创建 `Game.Core` 与 `Game.Gameplay` 两个 asmdef**；Presentation / NetworkAdapter / UI / Account / HotUpdate 留在 Assembly-CSharp。

原因：
1. FinalIK 与 xLua 源码均无 asmdef（编译进 Assembly-CSharp-firstpass），自定义 asmdef **无法引用** firstpass——若 Presentation 层建 asmdef 将用不了 FinalIK/xLua 类型，强行搬移插件源码风险大于收益；
2. 架构红线「Gameplay 不引用 FishNet/Animancer/UI」由 `Game.Gameplay.asmdef`（只引用 Game.Core + 引擎）在编译期强制——这是唯一必须由编译器保证的边界；
3. Assembly-CSharp 自动引用全部 autoReferenced 程序集（FishNet.Runtime/Animancer/Unity.Cinemachine/Game.*），其余层的脚本零配置可用。
