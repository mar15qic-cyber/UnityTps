# 07 开发路线与风险（原方案 §16 §17）

## 16. 两周开发路线（每天≈12h；含 RE4 维护缓冲）

| Day | 主题 | 交付物 / 验收 |
|---|---|---|
| **0（今晚）** | 工程整备 | 转 URP；Git 仓库；删模板；导入 FishNet(Pro)/xLua/Animancer/FinalIK + UPM 装 Cinemachine，跑通各最小示例；本方案落盘 Docs |
| 1 | 资产审计 + 移动 | **资产审计里程碑**：验证 TP 角色（须为标准 Humanoid rig，FinalIK 前提）/FP 手臂/武器动画 clip 可用性并定型（Animancer 只需 clip，无控制器配置负担）；占位场景 WASD+Jump+Sprint+MouseLook（CC 驱动、手感调参） |
| 2 | 武器核心 | WeaponDefinition/Runtime/Controller/View 四件套；一把枪完整：射击/弹道/弹药/换弹（ActionSystem 同步成型） |
| 3 | 动作+动画闭环 | ActionSystem 全状态（含打断矩阵）；**Animancer 接入**（半天：官方示例→mixer/layer/EndEvent）；FP/TP AnimDriver + AnimEventReceiver；切枪 1/2/数字键 |
| 4 | 表现层 | CinemachineCamera + 自定义组件：sway/bob/breathing/recoil/**ADS**；枪口特效/弹壳/命中反馈 |
| 5 | 后端 Day1 | webapi 骨架 + EF 建库 + 注册/登录(JWT)；Unity ApiClient 登录页 |
| 6 | 后端 Day2 | 档案/配装/升级/战绩 API；大厅 UI 流程（Login→Main→Loadout→Upgrade） |
| 7 | 联网 Day1 | FishNet 接入：房间创建/加入（房间码）；Player 生成；NetworkTransform 同步；远端 TP 动画（LocomotionState SyncVar）+ AimIK 瞄准方向 |
| **M7 检查点** | **首个可玩：两人局域网互看互跑**。未达成 → 触发 §17 降级线 |
| 8 | 联网 Day2 | 服务器权威战斗全链路（FireRequest→验证→Raycast→伤害→广播）；远端开火/换弹/切枪动画事件（§6.6 三端流程落地） |
| 9 | 联网 Day3 | 死亡/重生/战绩；**Prediction 专窗**：跑官方 demo→套用；成功则顺带 LagCompensator.Raycast（一处替换）；回退线=Day9 午 |
| 10 | 成长闭环 | 比赛结算→XP→升级→技能点→属性生效（Lua 公式串通前后端） |
| 11 | xLua 演示化 | Reload 热更演示链路；编辑器热重载按钮；Build 包从 StreamingAssets 读 |
| 12 | Arena + 打磨 | ProBuilder 竞技场定稿；三长枪+手枪数值配置；音效；MatchRecord(可选) |
| 13 | 缓冲日 | 修 bug、砍尾功能（手雷/ADS 若未完成此处决断）、录屏、README 架构文档 |
| 14 | 面试资产 | 演示视频(3–5min)、架构图文稿、深挖问答清单演练 |

> 每天 RE4 Demo 维护压缩在 1–1.5h 内；若当天 RE4 事务超时，优先砍本表「打磨」项而非架构项。

**里程碑式验收（不是功能清单而是可演示状态）**：
- M4：单人 FPS 手感完整（录屏可看）
- M7：局域网双人对跑互看
- M10：登录→对战→升级→强化全流程闭环
- M14：可部署演示包 + 可讲解架构

> **2026-08-25 重大事故与恢复（教训入档）**：Unity 重启后以空模板状态打开项目并**物理删除了 Assets 下所有内容**（绕过回收站）。根因疑似：杀进程后 `Temp/UnityLockfile` 残留 + Library 处于 PlayMode 崩溃状态，Unity 再次打开时 AssetDatabase 判定项目为空模板并清空 Assets。**恢复结果**：① git checkout 找回 6100+ 已跟踪文件（FishNet/xLua/FinalIK/Docs/插件全套）✅；② 17 个 Day1-3 源码脚本由会话记录 100% 重写 ✅；③ LPFP 资产包从 `E:\BaiduNetdiskDownload\Low Poly FPS Pack 3.2.unitypackage` 手工解包还原（989 项 asset → 716 文件，路径与原版一致）✅；④ **无法恢复**（从未 git add + Unity 删除不进回收站）：Arena 场景摆设、2 个 WeaponDefinition SO、4 个武器 prefab、场景组件接线。**待重建**（约 1-2h）：SO ×2 + FP/TP 武器 prefab ×4 + Arena 场景（Player 结构/相机/测试靶）+ 组件接线。**制度修订**：每完成一个 Job 立即 `git add -A && git commit`；Assets 全量纳入版本控制。

## 17. 风险列表（按 严重度×概率 排序）

| # | 风险 | 严重度 | 缓解 / 降级线 |
|---|---|---|---|

| 2 | FishNet Prediction 学习曲线（最陡技术点） | 高 | Day 9 专窗 + 官方 demo 起步；**硬回退线：NetworkTransform 方案**（局域网可接受），面试讲清取舍反而加分 |
