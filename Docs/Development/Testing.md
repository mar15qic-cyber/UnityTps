# 验证方法与结果记录

## 分层验证

| 层次 | 检查内容 | 能证明什么 |
|---|---|---|
| 编译 | Unity Console、dotnet build | 类型 / 依赖可构建 |
| EditMode | Policy、状态机、契约、UI 结构 | 被测试输入上的逻辑，不证明实机画面 |
| 后端测试 | 服务、HTTP、事务、迁移 | 业务 / 契约；InMemory 不证明 MySQL 行为 |
| 静态包验证 | 文件 SHA、身份、材质 / shader | 包完整与身份，不证明玩法 |
| 联网实机 | 两客户端与 DS，正常输入、截图 / 录像 | 实际被触发的行为和画面 |

后端从根目录执行：

```powershell
dotnet build fps-backend/UnityFps.Backend.sln --no-restore
dotnet test fps-backend/UnityFps.Backend.sln --no-restore
```

先 restore；MySQL 集成测试另需隔离配置，阅读 MySqlIntegrationTests 的开关和测试库限制。不要用真实玩家库运行破坏性测试。

Unity 测试在 Assets/_Project/Tests/EditMode 与 PlayMode，通过 Test Runner 选择与修改相关的类。RuntimeAudit / 诊断工具含特殊构建定义和注入动作；它们不是发布流程，不能默认启用或将诊断 DLL 混入最终包。启动 PlayMode 或脚本实机对局前确定测试范围。

## 定向检查矩阵

| 范围 | 必测行为 |
|---|---|
| 配装 / 商品 | 三背包独立保存重登、重复 / 空槽、未购买拒绝、旧预设迁移、种子重跑、配件与消音器迁移 |
| 背包 UI | B→数字键、鼠标、悬停、清单晚到、死亡复活、聊天 / 菜单 / ESC；TDM / KillRace 区域和锁存；失去资格后换弹不返图标 |
| 地图 | 六图空隙、表面、近掩体、楼梯移动、防越界 |
| 霰弹 | 缺 1–6 发、少备弹、每发到账、开火中断、切枪、死亡、延迟 / 乱序快照 |
| 表现 | 腰射、真实 ADS 与两款 1x、后坐、移动、换弹、投掷返回、Owner / 观察者手电 |
| UI / Boot | 1280×720、1920×1080、2560×1440；字完整、图比例、第一帧加载覆盖、错误重试 |

记录版本、账号 / 角色、地图 / 模式、输入步骤、实际状态、日志和截图。必须确认测试触发条件：ADS 输入不等于 ADS 状态有效，按换弹不等于开始换弹。脚本布尔统计不是产品通过率。

## 最终版证据的解释

Final20261001 沿用此前定向 EditMode 84/84 和构建 / 静态校验记录，最后一次脚本实机只执行一轮 KillRace。部分换弹、离区锁存和腰射画面有有效证据；完整瞄准、空仓换弹、仍有资格时的忙碌图标以及手电墙面印记未完整触发或复现。详细范围见 [版本记录](../Releases/Final20261001.md)。
