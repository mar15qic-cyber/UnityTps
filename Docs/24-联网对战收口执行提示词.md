### E.1 设计要点（含一处实施适配，先读懂再动手）

**【实施适配 1】G2 采用「服务器侧 pivot 俯仰同步」而不是给 FireRequest 加方向参数**（Docs/23 §P0 原文写的是"FireRequest 增 aimDir 快照"）。原因：加方向参数必须改 `WeaponController.TryFire` 的内部瞄准路径，而 WeaponController 是 LPW 基线测试活跃文件（B.1 冻结）；改为把俯仰同步到服务器侧 aimPivot 后，`TryFire` 内部已有的 `AimDirection = aimPivot.rotation × 后坐偏移` 自动恢复正确，**WeaponController 零改动**。方向快照参数留给 P4（LagCompensator）阶段再评估。把本适配写进你的阶段报告。

## L. 编码与 Unity 陷阱速查（本项目前科，写代码前对照）

1. **一个 MonoBehaviour 一个文件**——struct 与 MonoBehaviour 同文件会导致 prefab 上组件 missing（编译却不报错）。
2. 序列化字段默认值是 0 不是 C# 初始化值；乘法/倍率类字段需中性值 1 兜底。
3. `Rigidbody.velocity` 在 Unity 6 已弃用 → `linearVelocity`（如涉及）。
4. xUnit 无 `Assert.DoesNotContain(collection, predicate, "message")` 重载——用两行断言替代。
5. EditMode 测试里构建 TMP 组件必须 `SetActive(false)` → AddComponent → 配引用 → `SetActive(true)`（若 HUD 测试涉及）。
6. FishNet `SyncVar<T>` 必须 `private readonly ... = new();`（既有文件先例）；`ObserversRpc` 参数只用基元/字符串/Vector/枚举（载荷一律 JSON 字符串）。
7. `OnDestroy` 退订照抄 `NetworkWeaponState.OnDestroy` 的防御写法（离线销毁阶段不要读 FishNet 状态）。
8. 反射读写私有字段必须 try-null 兜底（域重载字段漂移风险）+ 中文注释说明原因。
9. 所有文件 UTF-8 无 BOM；中文注释禁止 GBK 写入。
10. shell 命令逐条执行，不要用 `&&` 组合（Windows PowerShell 5 前科）。
