## 3. harness 两处真根因（矩阵前修复，均有上轮误判）

1. **"leave confirm button missing" 真根因 = UIComponents.Button 结构，而非（只是）缺 ESC 前置**：
   `UIComponents.Button` 的 root 仅 RectTransform，**Button 组件在子物体 "Face" 上**——harness 原在根上
   `GetComponent<Button>()` 恒 null。修复：`GetComponent` 空时回退 `GetComponentInChildren<Button>(true)`。
   （ESC 前置 `TryConsumeEscape()` 仍必要且保留——`BeginLeaveConfirm` 要求 PauseMenu 态。）
   修复后 delta production 退出实测走通：`[Day4Harness] production leave: invoking real LeaveConfirm button path`。
2. **spin 驱动（新增 `-day4SpinSec N`）**：入 Arena 后等 `MatchLifecycle.InputFrozen=false`（InProgress）→
   禁用 InputReader → 反射写 `Move=(0,1)/Sprint=true/FireHeld=true`，每 0.5s 重写 `LookDelta=(2.0,1.5)`
   （pitch 顶 clamp 后朝天画圈开火——只产生 `[CombatRay] MISS`，零击杀风险、不提前终局）。
   提供"剩余玩家仍能移动/射击"的主动作证据源。
