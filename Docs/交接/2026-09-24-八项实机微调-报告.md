# 八项实机微调报告（2026-09-24）

> 任意代理或用户可独立复核；本报告对应工作区当前未提交改动。用户在实施中明确限定：只调整消音器，不改变其他配件位置。

## 结果

1. **迅速重开房间提示无服务器**：Dedicated Server 在 Ended→Idle 完成时立即发 Ready/0 心跳；如果断线心跳尚在传输，保留一次重臂心跳请求并在单飞闸释放后补发。后端开局遇到单实例仍在旧局退场或 Draining 时，在事务外以 250 ms 间隔最多等待 8 秒，回池后自动租用；无可用实例仍返回原 409。
2. **QE 探头**：进入时长从 0.18 s 调至 0.11 s，退出从 0.14 s 调至 0.095 s。保持原预测一致的线性推进方式。
3. **消音器**：LPFP Silencer 模型出口位于原模型 -Z，螺纹接口位于 +Z。三条共用模型的 Muzzle 目录项从 -90° 改为 +90°，按新朝向将接口落在枪口后 6 mm；瞄具、握把、激光和手电位置均未修改。13 把可装消音器枪械的 FP/TP 共 26 个视图完成静态几何测试和四角度渲染检查，生成图位于 `Temp/SuppressorFollowupAudit/weapon.*.png`。
4. **投掷**：按住左键时原生 FP 动画从 18% 平滑推进至 35% 的准备姿态；松开后从当前帧续播。HUD 给出准备百分比。投掷方向锁定松开瞬间视线，服务器核验方向后从真实生成点对准目标；远端投掷物由 NetworkTransform 单独插值，关闭代理 Rigidbody 双重插值及碰撞，插值缓冲改为两 tick。
5. **地速**：步行 1.58→1.68 m/s，冲刺 3.8→4.0 m/s；同步默认值与两份正式 RootMotionProfile 资产。
6. **摄像机后坐**：Cinemachine 在原本与 FireRay 同源的旋转反馈外，消费每把枪 SO 中已有的 `Recoil.ShakePositionAmplitude`，以有上限的位置后冲和指数恢复增加单发反馈；ADS 冲量减弱。16 把正式枪的数值仍逐枪由 `Day2_DemoBalance.asset` 管理。
7. **对局 HUD**：右下武器图标与弹药簇收紧对齐；移除顶部常驻操作提示；比分改成带红蓝侧标、时间、模式与实际击杀目标的顶部卡片。投掷操作提示只在右下投掷状态出现。
8. **团队计分**：生成时从认证 roster 写入队伍，击杀计分时再次按击杀者连接的认证 roster 校正队伍，避免依赖可能未同步的玩家 Team SyncVar；非法队伍不计团队分。

投掷 RPC 增加释放视线参数，因此 Client 和 Dedicated Server 的应用协议同升为 `fps-net-v15`，旧构建不能混用。
