## 现状与修复

1. **同账号双登录**：后端 AuthService 的 TokenVersion 原子自增与 JWT 验证已经存在。确切缺口是跨场景 SocialSession 每 3 秒轮询遇到 401 后忽略，旧客户端既不提示也不退出。ApiClient 现在对携带当前 token 的认证请求 401 发出失效事件；AppRoot 清认证、递增连接代际、断战斗连接、回大厅显示明确提示。请求携带的旧 token 与当前 token 不同、登录密码错误、网络超时均不触发踢出。策略为后登录者保留会话，旧客户端在下次成功收到认证失败响应时退出。不是设备永久绑定，也不是已部署事实。
2. **1× 准线**：两款 1× 镜共用 OpticAdsView。旧代码将分划投到射击轴，却只以整个屏幕判断镜窗可见性，没有镜窗裁剪；因此后坐、开关镜过程或视角偏移时可在镜外绘制。现在按 FP 相机投影镜窗建立内缩裁剪区，射击轴不被移动。矩阵为 9 枪 × 2 镜 = 18 个可安装组合；手枪已禁用这两款，狙击仅内置镜。共用缺陷意味着全组合均受影响风险，但不能等同每把枪在视频里都复现。
3. **Hitbox**：已有 BodyHitbox 下身胶囊、UpperHitbox、HeadHitbox（PlayerNetworkAdapter.EnsureBodyHitbox）；CombatResolver 选中碰撞体后统一将基础伤害交给 DamageableTarget，没有部位倍率。用户感受到同倍率是符合当前实现的。本次按“当前是否有”的问题做核查，没有擅自制定头/胸/腿的新平衡数值。
4. **投掷**：选择时已停在投掷动画 35% 位置，点击却重播开头。本次从持握位置续播，释放延迟 0.35→0.15 秒，动作 0.7→0.5 秒。所有三种投掷物降低接触摩擦 0.62→0.32、保留反弹系数 0.55，加入旋转，删除离地向下射线命中就强制 Sleep 的逻辑；网络插值 2→1、外推 2→0，减少碰墙后继续预测向墙内运动。实测投掷还暴露 TPLeftHandIK 在握点移除后访问空 target 的异常，已加空目标退出处理。
5. **闪光**：按用户描述实现相似曝光机制，不声称复刻 CS2 私有数值。正视近距离爆点可达 alpha=1 并保持全白，侧视/背身/远距更弱更短；墙体遮挡阻断，角色和投掷物本身不误作墙体。多枚闪光分别衰减取最大值，弱闪不延长强闪的全白。加入耳鸣和主音量暂时衰减，结束/切场景恢复用户音量；自闪、队友闪与敌人闪不做免疫，未加投掷者扣分。
