## 实施结果

| 问题 | 处理 |
| --- | --- |
| 雷达蓝色底板 | 直接引用频道/房间浏览器使用的 `Resources/UI/Maps` 原图，不重新着色。新增 MapRadarCatalog，记录原图拍摄相机的位置、旋转和正交尺寸，使玩家、队友、敌人观测点投影到相同图片。覆盖 arena、map_01～04；移除独立雷达相机与临时地图材质。 |
| AK 低倍镜偏离导轨 | 对 AK-47（稳定 ID 为 `weapon.m4`）的 optic.01、optic.03 单独校正夹具横向中心，偏移约 -1.797 毫米；同步移动 EyePoint、AxisFront 和 WindowCenter，保持瞄准轴与实体镜一致。 |
| 投掷物键位 | 默认从 Numpad3 改为主键盘 Digit3；继续支持设置页重绑。移除与其冲突的第三武器槽键读取。按 3 掏出、连续按 3 切换手雷→闪光→烟雾，左键投掷；滚轮切枪。用户原先的循环选择规则保留，已询问是否意指直接快投，当前未收到改变操作方式的回复。 |
| 枪上悬浮异物 | 视频中的黑条实际是 `OpticMountAdapter`，在 layer 0 被世界相机绘制，枪和瞄具在 layer 9 被 FP 相机绘制。已通过只改变该层的前后截图复现并确认根因。生成 FP 模型时统一层，重新应用配件时同步 AttachmentSocket 子树；覆盖缓存复用、投掷恢复与重生恢复路径。上一轮隐藏示例刀的处理没有解决这个转接座问题。 |
| 狙击镜 ScopeTexture | HUD 覆盖式瞄准镜与实体镜片两条路径均直接引用 LPFP `Sniper_01_Scope_Texture.png` 原厂纹理。保留原厂颜色与透明通道，不再使用自绘高倍分划。原图透明像素的 RGB 会被导入器扩边，材质现使用源 alpha，避免出现粗黑十字。 |
| 击杀后血迹悬空 | 视频末段约 141 秒可见敌人已倒地而红色血迹仍在原受击高度。项目 `BloodImpact_LPFP` 包含 5 秒的 `Blood Bullet Hole Particle`，角色根节点不随倒地骨骼运动，因此挂根节点仍会悬空。停用这一持久血迹子节点，保留 0.2 秒的瞬时血花，实例清理时间从 10 秒改为 1 秒。16 把原生枪共用此资源；环境弹孔与 LPFP 供应商源文件未改动。 |

投掷物循环和队友侦测广播沿用上一轮逻辑；本次没有改动多人广播协议。TrainingYard 是现有热更新地图，目录包含其投影，但它不在当前客户端四张内置地图中。
