## 5. 复盘修复的根因记录（Codex 提示词要求 6）

### 5.1 离线 FishNet NRE

- **现象**：Lobby→Arena 后离线 authored player 每帧 NRE（TPAimDriver.LateUpdate → NetworkCombatAuthority.IsOwnerPlayer；WeaponHudView.TryGetAuthoritativeAmmo 同类）。
- **根因链**：GameplayLoadoutBootstrap.Awake 对 Arena authored player 调 NetworkObject.SetIsNetworked(false) → 该 Player 上 NetworkBehaviour 的所有权缓存/Owner 未建立 → IsOwnerPlayer 直读 FishNet IsOwner（QOL 内解引用 null）→ 表现层每帧消费点触发。
- **修复**：FishNetLifecycleGuard 统一门（网络未启动 → authored player 视为本地玩家；已启动 → IsSpawned 短路后才读 IsOwner）；全局排查直接 IsOwner 消费点全部收口（含排查新发现的 NetworkLocomotionState.UseRemoteState）；未采用吞异常/禁用组件/删组件方案；未改 FishNet 源码。
- **证据**：FishNetOfflineSafetyTests 6 例（离线语义不抛异常）；编译 0 错；总集 225 用例无新增失败。在线真实路径待实机。

### 5.2 新武器弹药 1/0

- **现象**：SMG04/新 pistol 配装进 Arena 显示 1/0。
- **根因链**：Day2_DemoBalance.asset 用户补录中夹带 `#` 注释（Unity 资产 YAML 不支持）→ L131 解析失败 → **整个资产导入失败回退旧数据** → 补录与部分原有条目（rifle.02/smg.01 等 13 项）全部缺失 → DemoBalanceConfig.GetWeaponStat 缺项走 Sanitize(default) → MagSize 夹成 1、Reserve 0 → WeaponController 接受伪合法值构造 Runtime → HUD 稳定显示 1/0。
- **修复**：删除 3 行注释（最小干预，数值未动）；TryGetWeaponStat 显式查询 API + 缺项报错强化；完整性测试锁"正式武器 ↔ Balance 唯一条目"。
- **证据**：重导入后 Parser Failure 消失；execute_code 运行时解析 8 个 weaponId 全部 found=True 且数值符合预期（§1.4）；Balance 相关 4 条存量测试自愈转绿。

### 5.3 SMG04（及 Sniper03）Draw 错绑

- **根因**：定义资产 Draw 字段 fileID 直填错误——SMG04 引 7400062（run@smg_04，正确 7400064 take_out_weapon@smg_04）；Sniper03 引 7400032（walk@sniper_03，正确 7400030 take_out_weapon@sniper_03，后者由新增测试扫出）。
