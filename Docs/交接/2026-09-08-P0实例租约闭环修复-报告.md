## 2. 根因与修复（对应审计 §2）

根因链（与审计一致，实锤于现场日志）：
1. 旧契约 `players/disconnect` 成功返回 **204 无 body** → Unity DS 的 `DisconnectPlayerAsync` 把任何 2xx 折算成 `Accepted` 并**丢弃全部结果**；
2. `ServerHeartbeatTracker` 永远收不到"后端已释放"信号，本地持旧 roomCode → 心跳上报 Reserved+旧码 → 后端 409 → 重注册 → 若实例又被新房占用则回到 Reserved——形成"进程在线但不可租用"的僵尸；
3. 死房（成员从未连上 DS 的房间）没有任何清理路径：懒清理只看实例心跳新鲜度，而僵尸实例心跳一直是新鲜的。
