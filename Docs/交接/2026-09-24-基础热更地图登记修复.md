# 基础热更地图登记修复

用户在 02 客户端看到地图资源最新，但创建 NightRelay 房间时提示尚未发布与服务器匹配的版本。

根因：主机缺少 `.runtime/maps.json`，API 返回静态基础目录，其中 TrainingYard / NightRelay 没有 contentHash；同时基础六图启动没有注入 FPS_MAP_CONTENT_HASH。只下载资源不能满足地图目录与 DS 入场校验。

修复：新增 `Tools/PrivateTest/Initialize-BaseMapCatalog.ps1`，从已发布 maps-manifest.json 读取两个基础 Bundle 的内容版本及 SHA256，验证文件后原子登记目录；保留已有显式发布条目。Start-PrivateHost 在启动前调用它。Start-CloudServer 按地图读取目录内容哈希，分别传给 DS，并在退出时恢复原进程环境，内置地图不继承热更地图的哈希。

确认六图当前均为空闲后，通过正常托管关服/开服应用。实际验证：invite-map_04 与 invite-map_05 均 Ready、fresh=true、buildVersion=private-selfregister-20260924-02；目录哈希与 HTTP maps-manifest.json 完全一致，contentVersion=12。夹具验证两个地图生成与重复初始化不覆盖通过。

不需要重新打客户端；用户重启现有 02 客户端以重新获取地图目录，再创建房间。未代替用户进行账号登录、建房或实际对局；这些交互尚需实际确认。
