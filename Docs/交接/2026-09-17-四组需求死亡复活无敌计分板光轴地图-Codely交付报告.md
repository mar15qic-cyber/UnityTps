## 4. 工程事实（新踩坑）

1. EditMode AddComponent 不触发 Awake 的又一实证：ServerLagCompensation.Instance（Awake 赋值）在测试里为 null——需要静态实例的组件，测试必须反射补 Awake。
2. SyncVar<uint> 反射 Value 写入未初始化时安全（走 SetInitialValues）——EditMode 直驱 SyncVar 状态的既定模式扩展到 uint。
3. uint tick 差值必须走有符号 long（`(respawnAtTick - now)` 回绕=1.43e8 秒显示）。
4. 手写 EF 迁移可不带 Designer 文件：[Migration("id")] 直接标注在迁移类上即可被 Database.Migrate() 发现（模式：只加列的简单迁移手写，快照手工同步，省 dotnet-ef 往返）。
