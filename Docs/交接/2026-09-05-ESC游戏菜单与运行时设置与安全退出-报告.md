## 4. Phase D：房主退出支持边界（明确 blocker，未做假实现）

- **现状**：FishNet client-hosted（房主进程即服务器）。房主退出 = 服务器消失，>2 人局「房主退出不中断」**当前架构无法实现**。
- **本任务实现范围**：2 人局任一成员（非房主）退出/断线 → 服务器权威终局（PlayerLeft，离开者判负、剩余者判胜，双方提交结算）；>2 人局普通客户端退出 → 仅移除、其余继续（比分/计时/Phase 不变）。**房主退出**：菜单弹窗明示「你是房主（服务器随你的客户端运行）：你退出后服务器将关闭，本局对所有玩家结束」，确认后停止连接并回大厅；其余客户端经 MatchConnectionWatcher 走 HostLost 清理回大厅（本局作废、不提交结算）。
- **未实现（blocker）**：>2 人局房主退出且比赛继续（需独立权威服务器或完整主机迁移：状态快照+原子房主转移+客户端重连恢复验证）。在用户明确拍板拓扑方案并授权前，不做、不声称、不用假人数掩盖。
