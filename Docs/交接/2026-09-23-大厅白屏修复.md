# 客户端大厅白屏修复（2026-09-23）

## 原因与修改

用户提供的白屏在客户端日志 `Tools/Client/Logs/client-20260923_002214-48790d.log` 与 `client-20260923_002218-36620b.log` 中对应 `ArgumentNullException: shader`。调用链为 `LobbyCharacterPreview.Box → BuildRoom → Initialize → RenderTacticalLobby`。原实现仅以 `Shader.Find` 动态查找装备间 Shader，打包缺失时材质构造抛出异常。初始化又发生在大厅按钮构建之前，导致留下默认白色 RawImage，并中断页面构建。

- 新增 `Assets/_Project/Resources/UI/LobbyRoomLit.mat`、`LobbyRoomUnlit.mat` 及 meta，显式引用 URP Lit/Unlit Shader，随 Resources 打包。装备间通过复制材质资源生成实例。
- `LobbyCharacterPreview` 初始化失败时清理部分构造的场景、材质、相机与 RenderTexture，RawImage 恢复透明，提供明确错误文字；允许再次初始化。
- `LobbyPresenter.TacticalShell` 先完成大厅交互控件，再初始化可选角色展示。
- `TacticalUiAssetBuilder.EnsureRoomMaterials` 可重建所需材质资源。
- `TacticalLobbyAssetTests` 增加 Shader 资产依赖检查与缺失 Unlit 材质后的清理、透明显示和重试回归测试。
