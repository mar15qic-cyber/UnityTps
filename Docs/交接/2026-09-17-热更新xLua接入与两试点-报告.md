## §2 关键工程事实（新增，防重踩）
1. **asmdef 布局**：xLua 的 Gen 必须 与 Src 同程序集 → 根级 `XLua.Runtime.asmdef`（避免 WSA 托管插件 xlua.dll 与程序集同名冲突，故用 `.Runtime` 后缀）；`Src/Editor`、`Examples/13_BuildFromCLI/Editor` 各自嵌套 Editor asmdef（Editor 魔法目录规则对 asmdef 无效）。
2. **改配置后必须先编译再 Generate Code**——Gen 读的是编辑器域里已编译的配置类型；未编译就 Gen 会用旧配置重生（本次 2924 错误事故的根因）。恢复法：`Logs/HotUpdate/GenBackup_pre_first_gen/` 还原 → 编译 → 再 Gen。
3. **Resources 双扩展名**：`foo.lua.txt` 的资源名是 `Lua/foo.lua`（Unity 只剥最后一个扩展名），`Resources.Load` 必须带 `.lua` 中缀。
4. **EditMode 下 MonoBehaviour.Awake 不回调**（项目既有惯例）：HotUpdateRuntime.Initialize() 设计为幂等公共方法供测试直调。
5. **PS5.1 curl JSON**：`-d '{"k":...}'` 引号被剥 → 一律 `@file` 体（`p3_live_smoke.ps1` 样板）。
6. **后端静态文件根 = ContentRoot**：`fps-backend/src/UnityFps.Api/hotupdate/`（非项目根 fps-backend/）；gitignore 已配。
7. **既有缺陷修复（P3 顺带）**：`MatchService.SubmitForPlayerAsync` 无 matchId 分支把 C# 方法 `RoomStatus.Normalize` 放进 EF 谓词 → MySQL 下 500（InMemory 测试测不出，R02 上线起真库即炸；在线对局走服务器结算路径绕过）。修复=先取本人房间状态列再内存归一（与 RoomService 既有用法同风格）。
8. **租用链路协议门**：API 裸测建房不带 `clientProtocolId` → 房间冻结 legacy 期望 → 与 v5 DS 全不匹配 → 409 race-transient。真实客户端自动带，非缺陷。

## §5 有意偏离与遗留
1. **Addressables → 裸 AssetBundle**（偏离计划字面）：地图热更复用已验证的 manifest/哈希/版本目录链路，避免引入第二套目录机制；语义等价（bundle 通道 + fail closed），复杂度显著更低。计划中的 Addressables 初始化未做（包仍装着，未来要切换时 HotSceneLoader 是唯一替换点）。
2. **版本目录不可变约定**：发布脚本显式版本可重发同名版本（demo 便利），但正规操作建议只前进；回滚=换 manifest 指针。
3. **pool 诊断 DTO 未投影 mapId**（既有诊断面）：地图绑定在 DB/租用日志可查，未改（避免动既有契约面）。
