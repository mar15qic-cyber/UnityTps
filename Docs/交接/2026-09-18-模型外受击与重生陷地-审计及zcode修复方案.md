## 3. 目标与范围
必须实现：
- 复活后站桩也立即恢复有效 TP 待机姿态，不依赖移动、换枪或 ADS；原始 TP 位置、旋转与动画骨骼不能被死亡过程污染。
- 玩家移动阻挡仍使用 CC；射击受击只认可显式受击体。射线只经过 CC 外壳不再给该玩家扣血或生成该玩家的实体弹孔。
- 同一射线真实命中 BodyHitbox 时正常伤害；不能因 CC 更近而提前吞掉射线。
- 明确近似胶囊与身体轮廓允许差距；不承诺本轮变成逐像素蒙皮命中。
- 保护既有两段射线、墙遮挡、自身过滤、友伤、无敌、生命代际、回溯还原和正常移动。

默认不改第三方资源/Packages、不改移动参数与出生点高度、不新增骨骼级伤害倍率系统、不做全量资产重导入、不扩展后端或 UI。本票不授权发布新客户端/服务器。
若现有单胶囊无法达到后方空处不受击的实机标准，进入 §6 的几何升级判定；不能把只删 CC fallback 当作完整解决。

## 4. P1：先修 TP 死亡/重生生命周期
### 4.1 保存与冻结
- 在任何可能调用 Animator.Rebind 的禁用动作之前保存需要还原的 TP 根位姿。当前“先停写者，后保存”会有保存被 Reset 改过的值的风险。
- 为 TP 提供明确生命周期入口。优先采用图 Pause/Unpause 冻结，避免依赖 serialized Reset 的禁用副作用；如仍停用 Animancer，运行期局部控制停用策略并恢复原值，不能直接修改第三方包。
- 保留对 Animator、TPAnimDriver、TPAimDriver、IK 等写者的冻结和原始 enabled 状态记录；明确顺序，不依赖 GetComponents 返回顺序。
- TP 范围限定于模型子树，不能误停 Owner FP 图；DS/Host/纯客户端都要可空引用安全。

### 4.2 重生恢复
- 在权威死亡状态切换到存活的真实边界统一调用 TP 恢复；重复 RPC/SyncVar 求值幂等，不能每帧重置动画。
- 恢复模型作者基准与原始组件状态；显式清理动作层残留，强制重播当前有效 locomotion（复活基线为 Idle），在图和 Animator 有效时求值一帧。
- TPAnimDriver 的缓存 _currentState、方向平滑、步态相位与播放层一致重置；不能仅 enabled=true，也不能只改 OnEnable 的事件订阅。
- 组件本来就禁用时不要强行启用。池化/OnStopNetwork 清理与真正复活区分，避免退出时无意义创建图。
- Gameplay 不直接引用 Presentation 程序集。沿用现有生命周期桥方式或定义低层接口由 TP 实现，择一并记录，不建立反向程序集依赖。
- 远端平滑在“真正完成 ResetDeathVisual”后失效/对位一次；不能仅依赖 ObserversRespawned 先到时的失效调用。维护作者基准，禁止用倒地/平滑瞬态重新捕获基准。

### 4.3 取证验收
先保持现有 RespawnTrace，按需增加短时、节流诊断：
根/模型世界位置与旋转、hips 与双脚世界 Y、蒙皮最低点（必要时一次 bake，不能每帧）、死亡标志、图是否播放、Layer0 当前状态及权重、缓存/来源 locomotion。
普通 Renderer.bounds 可能是保守包围盒，不可单凭它证明皮肤穿地。
用 Idle→死亡→Idle 为最关键用例；修复前应能展示停播或异常骨骼证据，修复后站桩即恢复。缺乏授权运行条件时明确留作待验，不编造完成。

## 5. P2：分离受击与移动碰撞职责
- 在“选择最近有效几何命中”阶段过滤已识别玩家的移动 CC，而不是先选中 CC 再把 Target 设空。否则仍会被不可见外壳挡枪并生成空处弹孔。
- 玩家识别采用组件/显式角色约定，不能仅凭名字包含 Player；不跳过墙、普通可破坏目标或无关控制器。
- 移除玩家路径的子树 DamageableTarget 兜底。确需保留非玩家复合目标归属时，采用明确绑定，不能重新引入全子树猜测。
- 同根 fallback 若因新查询规则不再需要则删除；保留时不得跨过独立墙体。射线过滤规则应在相机、枪口、身体防伸墙三段一致。
- 明确 BodyHitbox 受击资格及生命周期；目前其 trigger 必须仍可查询。不要全局关闭 queriesHitTriggers 或改变玩家移动碰撞矩阵。
- RegisterCharacterControllerForRaycast 的 1mm Move 不再能作为射击修复。先验证是否有独立移动初始化用途，再决定保留/移除；不得顺带改出生沉降规则。
- 更新旧测试夹具：CombatResolverSelfHitTests.BuildVictim 用的是普通 BoxCollider 冒充根 CC。增加真实 CharacterController/显式移动体测试，不能靠原假夹具全绿宣称已验证。

## 6. P3：BodyHitbox、网络时序与特效对齐
### 6.1 几何审计与判定
完成 P1 后再录四向几何对照（前/后/左/右，站立与移动），同时显示逻辑根、可见 TP、BodyHitbox、CC 与实际射线。优先证明是否“模型恢复正确后原本错位自动消失”。
检查作者 TP 偏移（prefab 有 z=0.341）、缩放、旋转与初始化 InverseTransformPoint 的组合，不能把 0.341 直接当作已确认误差量并硬编码补偿。
对静止目标记录体表与胶囊误差，给出本模型实测结果；对移动目标分开记录客户端视觉时间、服务器 tick、请求/实际回溯 tick，不能把正常延迟补偿一概定为穿空命中。
DS Pin 分支不覆盖 Host，Host 也必须检查。回溯注册发生在 hitbox 创建之后；变更受击体集合必须同步历史记录与还原。

### 6.2 若仍有显著后方空处受击
本轮最低可交付为经模型实测校准、与有效站立轮廓匹配的受击代理；校准参数显式保存，不能依据单帧画面盲缩半径。
如单胶囊不能满足验收（持枪姿态下仍有明显可瞄准空区），报告事实并提出显式头/躯干/肢体复合代理方案。升级必须同时解决：
服务器姿态求值、受击体与客户端视觉时间的对应、多个碰撞体一次伤害、LagComp 快照/还原、死亡与复活启停。
不能只把碰撞体挂骨骼就宣称 DS 与客户端完全一致；此扩展先作为独立决策项，不能悄然扩大为全套骨骼战斗重构。
无实机证据时只能标记“模型外受击待验”，不得以放宽验收绕过。

### 6.3 特效
- 环境弹孔继续落在环境真实命中表面。
- 玩家命中区分短时血花/命中反馈与持久表面弹孔；胶囊代理命中点不能冒充蒙皮贴花锚点。
- 首选本轮玩家仅使用合适的短时角色命中特效，不把墙面弹孔 fallback 到玩家。必须保留皮肤弹孔时需要可靠表面投影/骨骼锚点；不在本票中臆造最近骨骼算法。
- 无敌、友军、死亡目标不能因 Damaged=false 就在空气中的玩家胶囊上生成墙面弹孔。
- 本地预测命中与服务器结算分别记录。跨端一致反馈若需新增 Target/Normal/Damaged/local point/shot id 等 RPC 字段，先提交具体协议变更设计，兼容性按项目现有协议机制处理；不要沿用旧报告“协议无需变化”的结论。
- 本轮不要求为远端枪口特效顺带重做整个开火协议。报告清楚哪些反馈是本地预测，哪些是权威，新增协议应作为明确范围变更。

## 7. 定向测试与实机矩阵
新增/扩展有行为断言的测试，不只测“字段存在”：
1. Idle→死亡→Idle：真实 Animancer 图与动画状态，复活后 Layer0 有效播放并经过一次求值；不需要输入。检查重复复活通知不重复重建。
2. Walk/Sprint/ADS/换弹时死亡、复活：动作层不残留；原本禁用写者保持禁用；FP 不回归。
3. 只穿过玩家 CC、避开 BodyHitbox：该玩家零伤害，射线应继续命中后方墙/目标，落点正确；没有后方对象时为 miss。
4. CC 在 BodyHitbox 前但射线真实穿过 BodyHitbox：正常扣血一次，最终点属于受击体。
5. 墙在前、墙处于 CC 与 BodyHitbox 之间、两玩家前后遮挡：不能透墙或错误归属。
6. 三段射线全部覆盖自身过滤/近墙遮挡；友伤、出生保护、旧生命历史拒绝规则不变。
7. 连续回溯/恢复后根与子受击体局部位姿无累积漂移；DS 与 Host 不因视觉平滑改变判定真相。
8. 玩家受击不生成环境弹孔；环境弹孔仍存在；预测特效不得用来断言服务器掉血。

建议回归现有套件：
CombatResolverSelfHitTests、TwoStageHitPhysicsTests、TwoStageHitResolverTests、
DeathVisualGroundingTests、OwnerDeathRespawnSnapshotTests、RemoteVisualSmoothingTests、
RespawnAmmoAndImpactParentTests、LagCompGenerationTests、LagCompensationPolicyTests。
旧 ImpactParent 测试只证明父子挂接，不证明贴身；按新的产品语义更新断言并说明原因。

实机（依执行代理授权安排，未运行不得填通过）：
- DS + 双客户端，静止受害者四向轮廓扫描；对照射线和实际服务器 HP，重点后背空处。
- 至少连续 5 次站桩死亡/复活，复活后 5 秒不移动，再移动；每次立即正常站立。
- 移动/跳跃中死亡、复活，持步枪/手枪，受害者 Owner 与另一观察端同时观察。
- DS 与 Host 分别覆盖；延迟条件记录实际 tick，不关闭 LagComp 掩盖问题。
- 墙前、近墙枪口、友军、无敌、迟到旧生命射击回归。
验收不能只检查 rootY 或 Animator.enabled；必须检查可见骨骼姿态与实际播放。
