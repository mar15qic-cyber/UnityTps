## 实现

- 私有与公网邀请构建分离，私有 HTTP 仅允许匹配预置组网地址；正式公网宏不能通过修改配置降级。
- Windows 图形启动助手检测 ZeroTier、引导官方安装、通过提权助手加入网络；首次设备编号可复制给主机授权。检测主机和热更发布身份，重复游戏进程不重复启动。连接路径未知时明确标未知，不将 HTTP 成功冒充游戏 UDP 成功。
- 主机控制台支持首次配置、五图启动、状态显示、停止新入场/排空、有限自动重启、设备批准入口和账号管理。API 内部监听与组网玩家监听隔离，玩家接口无法访问实例控制面。数据库保持主机侧配置。
- 当前 Windows 用户 DPAPI 保护登录会话，不存密码；恢复时重新查询服务端身份与配装，登出或凭据失效后清除。邀请码模式隐藏注册入口。
- 大厅地图内容独立通道，每 30 秒检查及手动更新，不更换运行中的 Lua 根目录；下载和进房互斥，取消/失败保留旧指针。地图列表显示待下载与准备中。
- 新地图目录可原子发布，独立 Bundle/DS 构建工具及发布脚本已提供；DS 入场校验实际本地 Bundle 哈希。更新既有地图时，控制面以事务和版本令牌取得 Maintenance 状态，旧心跳不能恢复 Ready，再停止属于工具的空闲实例。
- 日志沿用固定字段脱敏导出；主机操作不自动上传数据、不自动购买服务，不改云服务器。

## 未验证项与边界

**接入、体验、延迟补偿正确性均为未验证**。本次没有实际修改防火墙、部署玩家监听器、操作 ZeroTier 控制台或让外部玩家对战。首次安装/UAC/设备批准、干净 Windows 机器启动、真实 UDP 握手、五图长时测试和 8 人负载均需要实测。

正式第六张地图由用户制作，当前未提供。新地图工具和临时地图构建已验证，但尚未执行发布—不重启进入对战的端到端测试；不能将构建、纯逻辑或安装测试作为该链路已通过的证据。新地图必须使用现有代码及网络资源，新增代码需要重新发包；网络预制体注册和场景资源一致性仍需人工复核与实际入场验证，程序集哈希不能独自证明资源表兼容。

主机控制台依赖现有 MySQL 服务，不自动安装数据库。组网授权仍需管理员在 ZeroTier 后台确认；无法保证首次安装完全无人工步骤。组网规则由网络管理员配置，本轮没有账户权限替用户在线设置规则。
