## 2. MovementSnapshot/ReconcileAction 专项（优先项）

### 2.1 生产链路追踪结论
链路：RunOwnerPrediction（TickAccumulator 固定步）→ PredictionBuffer.TryStore+RecordPredicted →
SendUnackedCommands 批量（每 2 模拟 tick，冗余 12 条）→ 服务器 ServerTick 队列消费 Locomotor.Simulate →
TargetAuthoritativeState(TargetRpc 每 tick) → ReconcileGate（ACK 门）→ 配对预测快照 →
Reconciler.Decide → None/Smooth/DivergenceSnap → HardSnapTo 对位+重放 → ApplySmoothCorrection 表现平滑。

### 2.2 修复前缺陷（实证）
1. **重复 ACK 快照静默硬对位**：服务器 30Hz 推快照 vs 客户端 15Hz 批量上传 → LastClientTick 相等的
   重复快照是常态；旧乱序门仅拦 `<`，相等快照穿透 → 配对历史已被剪 → 误判"历史缺失" →
   HardSnapTo（ApplyAuthoritativeSnapshot 直写+重放）每快照一次。空闲/丢包/倒计时冻结期全命中。
   静默无计数（SNAP 日志只在位置 Snap 分支）——Day3 "仅 1 次 SNAP" 的指标掩盖了该路径。
2. **LastClientTick==0 初始对位重复**：首个输入确认前每快照硬对位一次。
3. **速度/朝向/移动分支完全不参与决策**：Reconciler.Decide 仅比位置——垂直速度反向、水平速度错误、
   yaw 跨域、grounded/airborne 分叉均不触发校正，速度错误靠后续位置漂移间接暴露。
4. **ApplyAuthoritativeSnapshot 不恢复 _coyoteTimer/_landTimer/_sprintIntent**：硬对位后这些影响
   跳跃/落地分支的计时仍是客户端旧值，下一 tick 继续分叉。
5. **接管（OnOwnershipClient）不清理预测基线**：同账号接管后 _localTick/_buffer/_lastAcked 残留前任会话。

### 2.3 修复设计（字段决策表）

| 字段 | 触发动作 | 容差/规则 | 依据（Locomotor.Simulate 实际消费） |
|------|---------|-----------|-----------------------------------|
| Position | 0.03 平滑 / 0.75 硬校正（不变） | 既有 | 既有语义 |
| Rotation(yaw) | Δ≥4°，连续 2 快照 → Snap | YawConfirmTicks=2 | SimulateGround 以根 yaw TransformDirection——yaw 分叉直接改变水平速度方向；相机 pitch 在 CameraPivot 节点不进快照，不压视角 |
| HorizontalVelocity | Δ≥0.35m/s，连续 3 快照 → Snap | 走速 1.58 的 ~22% | SimulateAir 的 MoveTowards 起点 + _groundSpeed 恢复 |
| VerticalVelocity | Δ≥2.0m/s，连续 3 快照 → Snap | 跳跃初速 ≈6.96、重力 22：1-2 tick 落地相位差 ≈0.7-1.5 必须容忍 | 重力积分/落地钳制分支 |
| LocomotionState | 跨 Grounded{Idle,Walk,Sprint,Land}/Air{Jump,Air} 组，连续 3 快照 → Snap | 同组内差异（Idle vs Walk）不动作 | CC.isGrounded 决定 SimulateGround/SimulateAir 积分路径；State 是衍生量，分组才对应模拟分支 |
| GaitPhase | 不触发 | Snap 恢复时已恢复 | 相位分叉数 tick 内转化为位置差，由 Position 兜底；单独触发会每快照回滚 |
| Dead | 终态前置处理（不受 ACK 门拦截） | — | 死亡后输入停止，LastClientTick 相同的重复死亡快照是常态 |

滞回（DivergenceGate）：速度/状态连续 3 快照（滤落地/起跳 1-2 tick 瞬态）；yaw 连续 2（无瞬态来源）。
任一快照一致即清零。**时间对齐纪律**：比较对象=同一已确认 tick 的配对预测快照（不是当前本地状态），
网络滞后造成的"服务器朝向/位置旧于本地"不会进入比较——正常转头不被拉回。
