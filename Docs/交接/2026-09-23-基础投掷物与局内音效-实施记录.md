# 基础投掷物与局内音效实施记录（2026-09-23）

> 任意代理可独立阅读。此文记录当前工作区实现与验证状态；尚未提交 Git。工作区原先已有大量其他未提交改动，不能整体清理或重置。

## 已实现

- 三种投掷物的正式 ScriptableObject 定义、目录资产、FishNet 预制体及注册。参数：手雷 1.75 秒／3.5 米／100 中心伤害／0.75 秒视觉；闪光 1.25 秒／9 米／最长 1.75 秒；烟雾 0.75 秒／3 米／14.25 秒。投掷初速度为前向 12 米／秒、上抛 2 米／秒，继承 30% 水平速度。
- G／H／J 可重绑直接投掷；每次出生各一枚；投掷动作在 0.35 秒释放，释放前中断不扣库存。服务器验证请求序号、生命、阶段、动作与库存，并在服务器模拟带物理材质的刚体；客户端接收 FishNet 轨迹。手雷沿现有伤害与击杀归属链路处理衰减、遮挡、自伤及 TDM 友伤规则。闪光在客户端按相机位置、朝向及遮挡计算；烟幕从起效位置投射到地面。
- LPFP 第一人称投掷动画、三种模型和现有特效／投掷／碰撞／起效声音已接入；不使用演示 `GrenadeScript` 的伤害。投掷库存显示在 HUD。
- 本人保留现有 2D 枪声，远端按服务器确认的开火事件在枪口播放 3D 枪声；16 把正式枪械绑定现有 `WeaponAudioProfile`。步行／奔跑循环按本地或同步步态播放，投掷碰撞有速度阈值和冷却。新增 `CombatAudioConfig` 管理脚步、远端枪声及碰撞音频参数；所有新增音源遵循 Master／SFX，批处理服务器不创建音源。

核心实现：`Assets/_Project/Scripts/Gameplay/Combat/ThrowableController.cs`、`ThrowableProjectile.cs`、`ThrowableDefinition.cs`、`ThrowableCatalog.cs`，以及 `Assets/_Project/Scripts/Presentation/Audio/FootstepAudioView.cs`、`RemoteGunAudioView.cs`。正式数据位于 `Assets/_Project/Resources/Throwable*.asset`、`CombatAudioConfig.asset`；生成器为 `Assets/_Project/Editor/ThrowableContentBuilder.cs`。

## 验证证据

- Unity 编译通过。相关 EditMode 用例 30/30 通过，其中 `ThrowableImplementationTests` 5/5；覆盖配置数值与引用、键位、请求序号、阶段、伤害／友伤／遮挡及逐枪音频绑定。
- Arena 离线实测：三种投掷均扣 1→0，烟雾持续存在；释放前死亡会中断动作且不扣库存，释放后投掷物继续生效，复活重置库存。四张轮换地图完成烟雾投掷抽查。
- 单进程 Host 冒烟：Owner 初始库存 1/1/1；投掷烟雾后库存减至 0；生成物 `NetworkObject` 在服务端和客户端均已初始化。此测试绕过正式票据和房间流程，不能替代远端客户端验收。
- 物理脚本模拟：斜墙接触后 0.30 秒时速度由初始 +X 改为 `(-1.938, -0.946, 8.006)`，出现沿表面偏转；0.05 米墙厚、50 米／秒球体在 0.20 秒时停在墙前 x=11001.880，未穿过 x=11002 的墙。此为相同物理参数的隔离测试，仍需正式地图实测手感。
- 客户端和服务器构建成功，分别位于 `Builds/ThrowableValidationFinal3/Client/UnityFpsClient.exe` 与 `Builds/ThrowableValidationFinal3/Server/UnityFpsDedicatedServer.exe`。最后检查 Unity 控制台无错误，编辑器已退出 Play 模式。
