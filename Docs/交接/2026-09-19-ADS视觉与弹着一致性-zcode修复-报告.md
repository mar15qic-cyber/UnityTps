## 1. 逐项修复（A1–A6）

### A1（P1）：眼点只对 x/y、z=0、无旋转 → 完整光轴姿态解
- 根因确认：`FPWeaponMotion.ComputeAimAlignmentPose` 瞄具分支（旧 394–408 行）只求 x/y 平移、z 恒 0、旋转 identity 提前 return——眼点停在作者腰射深度，眼睛远在镜后，镜窗又远又小（图一现象），与校准数据是否正确无关。
- 修复（`8b425465`）：
  - `AttachmentCalibration.OpticAimCalibrationRow` 扩展 `axisFrontPointLocal`（光轴前点，零=挂点前向 -X）、`windowCenterLocal` + 半宽/半高（镜窗几何，零=未标定）；新增 `OpticAimData` 聚合读取 `TryGetOpticAim`（组合覆盖优先/瞄具默认兜底，语义与眼点一致）与 `DataVersion` 自增（任何写/删/OnValidate 都递增）。
  - `OpticAimGeometry.SolveAimLocalRotation/SolveAimLocalPosition`（纯数学）：把 (光轴, up) 帧对齐到父系 (前向 +Z, 上 +Y)，眼点经旋转后精确落在 FP 相机位。**固定点性质**：应用解后重测必有 eye==camParent、axis==+Z，与相机旋转/后坐无关——旧实现混合 `cleanRootRotation` 的写法在相机旋转下非固定点，疑为 A1 残留偏差来源之一，已一并消除。
  - `FPWeaponMotion`：Legacy 路径启用完整解（位置 3D + 旋转 + 滚转对齐）；动态机瞄枢轴层在光轴解生效时让位（旧代码会让"机瞄后瞄对中"拖拽已被光轴对齐的枪根，双写者冲突）；校准数据 `DataVersion` 变化即重解（校准窗口改表保存后无需重进场景）；死亡/复活既有失效链不变。
  - **V2（LPW anchored dual pose）路径行为保持不变**（仅 x/y + 作者 z、无旋转解）——LPW 实验线只读红线，非样板目标。
- 生效链路：校准行 → `TryResolveOpticAimRoot`（挂点→root 局部系，位姿不变量）→ 冻结解缓存（入镜过渡逐帧解、满 ADS 冻结）→ 统一单次绝对写回。后坐/sway 通道在解之上叠加，无反馈回路。

### A2（P1）：1x 分划与实体镜身不共享投影 → 分划锚定真实镜窗投影
- 根因确认：`OpticAdsView` 分划是全画布居中程序化图形，与镜窗几何无约束；图一截帧分划完全不可见（可能为 bootstrap/绑定/profile 缺失之一，需实机区分——但无论哪种，旧分划与镜窗都无几何关联）。
- 修复（`8b425465`）：`OpticReticle/ReticleFrame/Tactical` 三层结构——ReticleFrame 每帧把分划锚到真实镜窗中心经 FP 相机的投影位置（与 FPWeaponMotion 共用 `OpticAimGeometry` 同源语义）；镜窗中心出画面 12% 边距时分划渐隐（不硬贴屏内掩盖对位错误）。无校准数据/相机不可用时归零=旧居中行为（诚实降级）。分划尺寸保持 profile 授权值（图二参考中分划是窗内小图形，不做窗口尺寸缩放）。

### A3（P1）：伤害射线与曳光平行 → 跨相机屏幕匹配收敛
- 根因确认：`WeaponView` 旧实现 start=当帧枪口、direction=FiredDirection、长度=点积限长 4.25m，且 LateUpdate 每帧把整条线重贴当前枪口——与命中点只是平行线，还被后坐拖着走；FP(45°)/世界(60°) 双相机投影不同，简单换终点也会屏幕不重合。
- 修复（`8b425465`）：
  - **每发快照冻结**：起点=开火帧枪口世界位（不再逐帧重贴，LateUpdate 重放已删除）；已发出的飞行曳光不随后坐/枪口动画移动（贴枪口火光仍跟枪）。
  - **跨相机收敛**：终点经 `CameraProjection.TryMatchAcrossCameras`（世界相机投影 → FP overlay 相机反投影，纯数学）落到真实弹着点的屏幕位置；远段飞行段放 Default 层世界相机直接渲染（其终点天然投在权威屏幕位），接缝点反向匹配消除双相机视差断线——近段（FP 层，与枪模同投影）+远段（Default 层）在合成画面连续，且 Default 层被倍率镜 scope mask 包含 → 镜内有弹道。
  - **逐弹丸池化**：8+8 段 LineRenderer 池，霰弹逐弹丸用各自真实终点（主方向配别家终点的问题消除）；近命中（<1.2m）单段直达匹配终点；相机缺失/终点在背后等异常路径回退限长直线（诚实降级）。
- `TracerScreenMatchTests` 锁死数学性质：投影往返、跨 FOV 收敛（匹配点在 overlay 相机视口 == 源点在世界相机视口，误差 <1e-3）、背后点拒绝、深度钳制。

### A4（P1）：预测/确认无闭环、散布不同步 → shot 级权威广播 + 确认消费

- 修复（`8a520b8e`）：

  - 服务器：`ObserversShot` 升级为全量载荷广播 + `OnRemoteShotGlobal` 静态中继；**Owner 定向确认**（TargetRpc，接受=载荷即权威结果）与**拒绝回程**（死亡/DUP/预检/TryFire 拒绝四条路径全部通知 Owner）。

  - **观察者弹道**：`RemoteShotFxView`（运行时自挂载）消费全局广播，为非本地玩家逐发补 Default 层世界弹道（终点=服务器权威结果；逐弹丸）——旧实现远端开火没有任何弹道表现。
