### 校准方法（可复核）

- **FP**：Muzzle 挂 weapon 骨下，localPos/localRot = 原厂 FPSController `Muzzleflash Particles` 节点的 weapon 骨局部值（旧 10 把 Muzzle 与该基准逐字节一致——方法与校准同源）。Handgun03 的 Muzzle 保留在 slider 骨骼下（旧枪 Handgun02 同款结构），局部值换算至 weaponLocal 精确等于原厂值。
- **TP**：根局部空间 (x=主枪体 x 中点，y=主枪体 y 中点，z=联合网格前端 maxZ)，localRot 恒 identity。公式由旧 3 把（SMG01/Handgun02/Sniper01）现值反推得出且误差 ≤0.1mm。
- **火光 Prefab**：共享 `Resources/MuzzleFlash_LPFP` 未做尺寸修正——票据要求"挂点正确后仍过大才统一修正"，挂点修正后待实机复验再定（禁止逐枪缩放掩盖坐标错误）。

## 2. 切枪输入实现（数字键 + 滚轮 + Q）

- **InputReader**（输入唯一采样点）：新增 `SwapAxis`（滚轮方向 ±1，只取方向不累计）与 `QuickSwapPressed`（Q 键经 SettingsKeyMap.QuickSwap 采样，可重绑）。
- **SettingsKeyMap**：`Action.QuickSwap` 默认 Key.Q，已入 Bindings 表（含 PlayerPrefs 键 `unityfps.key.quickSwap`）。**注：键位重绑设置页 UI 当前工程中不存在**（SettingsKeyMap 只有数据层+InputReader 消费端），UI 建立后遍历 Bindings 自动出现——此为现状事实而非本次删减。
- **Arsenal**（槽位唯一写者）：
  - `TryScrollSwap(dir)`：+1 上一把/−1 下一把，首尾循环、跳过 null/空槽、仅一把有效时无动作；
  - `TryQuickSwap()`：切到 `_previousSlotIndex`（无历史/槽无效时不动作）；
  - 同帧优先级：数字键 > Q > 滚轮；
  - `_previousSlotIndex` 只在 **EvaluateSwap 交换点**（旧枪收枪时长耗尽真正换装）记录——失败/被拒/中断/未到交换点的请求不污染历史；
  - **`OnSlotIntentResolved(slot)` 单一通路**：TrySelectSlot 真正发起切枪动作（TryStart 成功）时触发一次；初始化装备、失败、忙碌不触发。
- **PlayerNetworkAdapter**：删除原"读 SlotPressed 自行推导"的重复路径，改为订阅 Arsenal.OnSlotIntentResolved → `SubmitSwitchRequest(slot)`——三种输入线上提交同一 resolved 目标、每次解析只提交一次；服务器 Host 本地切枪由 SubmitSwitchRequest 既有守卫自然旁路。
- **WeaponHudView**：操作提示更新为 `0-9/WHEEL/Q SWITCH`。
- 不绕过 TrySelectSlot/ActionSystem/Draw-Holster 时序/服务器验证（滚轮与 Q 最终都走 TrySelectSlot，忙碌期被 ActionSystem 自然拒绝）。

## 3. 动态准心：诊断与修复

### 断点诊断（票据要求先诊断后动手）

1. **接线实测（Arena 实例 + 网络 prefab 双查）**：Arena 场景 Player 上 `WeaponFireContextProvider` 存在且 aimState/locomotor 引用齐全；联网生成 prefab `Player_Day2_Rebuilt` 同样带 provider 且引用齐全——**接线不是断点**。
2. **真正的根因**：新增 6 枪在 `Day2_DemoBalance.asset` 的条目**没有 Accuracy 块**（只有基础字段）→ `SanitizeAccuracy` 对 MovementSpreadMax/SprintSpreadExtra/AirborneSpreadExtra/ShotBloomPerShot **只 Clamp 不兜底** → 四值全 0 → 移动/冲刺/滞空惩罚与开火 Bloom 恒 0 → `CurrentSpreadDegrees` 恒等于基础锥角 → 准心只随开火 Bloom 动（新枪连 Bloom 也 0 → 完全静止）。旧枪数值齐全所以正常。
3. **修复**：6 条目补 Accuracy 块（同族参照：手枪 03/04 ← handgun.02；SMG 03/04/05 ← smg.01；狙击 03 ← sniper.01），重导入后运行时实测全部生效（§5 证据）。
4. **防御加固**：`WeaponFireContextProvider.Awake` 增惰性解析（serialized 引用悬空时自动在玩家层级找齐）。
5. 表现核对（数值→1080p/60° FOV Gap 映射）：Idle→Walk +5.9px、Walk→Sprint +33px、Idle→Air +20px（全部 ≥ 可感知阈值）；收拢 SmoothSpeed=180px/s 从冲刺 Gap 回 MinGap 约 0.24s（落在 0.15~0.35s 窗口）；HideOnSprint 保持 false；ADS 隐藏规则未动；准心与弹道同源（CurrentSpreadDegrees 单一数据源，无假缩放）。
