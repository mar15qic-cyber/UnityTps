# 低倍镜准线修复（2026-09-23）

任务来源：用户在逐枪核查后明确要求“修复”。范围为 Scope_01 / Scope_03 两款低倍镜，共 13 把正式可安装枪械、26 个组合。此前 1× 镜修改不作为本任务的修复证据。

## 修复内容

- 为两款镜增加 prefab 局部空间的真实有效孔径数据；准线与镜内画面挂在瞄具本体下，随安装姿态、动画、后坐一起运动。取消这两款镜从整个世界包围盒估算位置/尺寸的路径。
- ADS 构图与镜片绘制共用同一光轴和孔径。Scope_01 的有效半径为 13.6 mm，Scope_03 为 12.2 mm，均内接于对应模型的镜圈。分划圆盘自身限制绘制边界。
- Scope_03 恢复实体镜，不再因错误眼点/包围盒计算失败而退回全屏 overlay。
- 修正圆盘三角形朝向及 UV 左右方向。镜内相机优先使用玩家主相机；旧路径会误选只渲染 UI 的 StaticUiCamera，导致黑镜片。
- 按 FP 相机下的镜片屏幕占比与世界相机 FOV 计算镜内视场，消除两台相机位置不同时的倍率误差；保持两款镜的配置倍率 3×。计算在枪姿态更新后执行。
- 为分划生成 mipmaps 并启用三线性采样，增大低倍分划线宽，避免 P90 等小镜片中细线消失。橙色尖角尖端对齐瞄准中心。
- 配件目录生成器也写入孔径标定，避免下次重建目录覆盖修复。
- 连射复测发现离线 authored player 的网络缓存可能尚未建立，`TryFire` 及 `WeaponView` 直接读取 `IsServerInitialized` 会间歇性空引用；现在先用现有 `FishNetLifecycleGuard.CanSubmitRpc` 判定，只有有效在线对象才走预测分支，离线正常播放开火表现。
