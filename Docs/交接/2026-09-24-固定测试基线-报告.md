## 本次启动问题

Windows PowerShell 5.1 默认按系统编码读取无 BOM UTF-8 发布清单，导致中文启动文件名乱码，GetFullPath 抛出非法字符。`Tools/Cloud/Start-CloudServer.ps1` 已明确以 UTF-8 读取发布/构建清单。`Test-CloudScripts.ps1` 增加中文文件名及无 BOM UTF-8 夹具，使用 Windows PowerShell 子进程回归。

真实旧包预检查已越过路径及完整性检查；随后因 5080 被未托管进程占用而拒绝启动。检查时占用者为 PID 31968，路径 `fps-backend/src/UnityFps.Api/bin/Debug/net8.0/UnityFps.Api.exe`。没有结束该进程；PID 后续可能改变。
