## 修改

1. `WeaponHudView.cs`：保留网络 Owner 查找/重绑；事件和每帧刷新均读本地 `WeaponController.Runtime`。该 Runtime 已由权威快照纠正并扣除待确认射击，HUD 不再用原始 SyncVar 覆盖预测，也不再屏蔽在线扣弹事件。
2. `MovementSimulationTypes.cs` / `PlayerNetworkAdapter.cs`：每个移动输入带 `HasViewPitch/ViewPitch`，采样包含当时可见后坐的俯仰；服务器按已消费输入记录瞄准历史，绝对采样消除拒绝射击导致的积分偏差。有限值和范围校验为 -124°～89°（基础 -89°～89°，上抬后坐最多 35°）。Host/离线构造路径继续支持无该采样的命令。
3. `ObserverTimeline.cs` / `NetworkCombatAuthority.cs`：未探测到实际观察目标时使用最近收到的服务器 tick，不额外减去远端玩家插值延迟。实际观察目标仍使用它自己的已呈现 tick；服务器 200ms 时间窗保持原值。
4. `WeaponRuntime.cs` / `WeaponController.cs`：普通开火 ACK 即使改变弹匣也不会误取消正在预测的换弹；Ready 快照的备弹消耗用于识别已完成换弹。晚到 Reloading 快照恢复动作计时器；权威换弹完成时释放动作槽，避免无计时器的永久 Reloading 或二次装填。
5. `GameProtocolIdentity.cs`：移动输入 wire 结构变更，协议升至 `fps-net-v20`。客户端和 DS 必须成对重建。

### 瞄准输入的边界

绝对俯仰是玩家瞄准输入，包含客户端可见后坐，不是客户端命中/伤害结果。校验使用服务器已消费的同 tick、同生命输入，位置/遮挡、身体 yaw、射速、弹药、ADS 上限、散布、命中和伤害仍由服务器处理。25° 射击方向一致性限制及 200ms 回溯限制未扩大。本改动不声称能独立识别客户端的自动压枪输入；它解决合法预测与权威射击集合不一致时的永久俯仰漂移。

## 实机复测

1. 先重新构建并重启 DS，再使用更新后的 Editor 或客户端；启动日志两端均应为 `fps-net-v20`。旧 v19 DS 与当前 Editor 不兼容，须先更新 DS。
2. 使用录屏中的 HK MP5：按住开火打空、空仓换弹、连续再打空；再做半匣换弹、按住开火同时换弹、主副武器切换后重复。
3. 验收每发 HUD 立即扣弹；打空后停止有效开火；每次换弹弹匣与备弹守恒，后续仍可再次换弹；服务器不再持续密集报 InvalidAim/InvalidTime。
4. 用第二个客户端确认有效伤害、观察目标的回溯射击，以及转头/压枪后的命中；EditMode 不能替代真实网络帧序和录屏观感验收。
