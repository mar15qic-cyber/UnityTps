# 2026-09-17 远端表现两问题修复报告（Codely）

日期：2026-09-17。问题来源：用户双端实机 + 录像（`Desktop 2026.09.16 - 23.42.28.06.mp4`）。主工作区脏区直改，**未提交 git**。

## 1. 问题与根因

### 问题 1：远端玩家移动不丝滑（腿部掉帧感）
- **根因**：方案A 远端根/CC 钉在最新权威位姿（NT 插值=1）后，根以 ~30Hz 阶梯瞬移；视觉平滑的**指数追随**（τ=0.07s）在两段样本间先快后慢 → 宏观顿挫。算法选择问题，非丢包/帧率。
- **修复**：`RemoteVisualInterpolationBuffer`（新，Gameplay/Movement，纯逻辑）——快照缓冲插值：样本仅在根位姿变化时推入（防渲染帧率污染到达间隔 EMA），渲染时刻=now−自适应延迟（EMA×2.1 钳 [0.05,0.25]s），两样本线性插值。碰撞根不动（方案A 语义不变）；死亡停写/瞬移与复活直接对位语义保留；旧指数追随常量保留供 A/B 旧路径。

### 问题 2：远端 TP 抬头/低头立即回正
- **根因**：纯 DS 上 `OnStartClient` 不回调、`OnStartServer` 从不去激活 `localOnlyRoot` → 远端玩家 `FPMouseLook`（_pitch 恒 0，DS 无输入）**每帧 LateUpdate 把 `ApplyRemotePitch` 写入的权威俯仰清零**；`_aimPitch` 只在消费输入的瞬间闪现 → A 看到 B 抬头即回正。
- **修复**：`OnStartServer` → `DeactivateLocalPresentationForServer()`（`localOnlyRoot` 整树失活 + `ownerOnlyComponents` 禁用；Owner.IsLocalClient 拥有者跳过，FN weaver 禁 IsOwner）。失活 Transform 的 localRotation 读写不受影响，服务器俯仰链（ApplyRemotePitch→TrySyncAimPitch→SyncVar）与服务器开火 aim（aimPivot）从此保持权威俯仰。副带效果：DS 上 Main Camera/AudioListener/FP 臂/HUD 全部不再空跑。
