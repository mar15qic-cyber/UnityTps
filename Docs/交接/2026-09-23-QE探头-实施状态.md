# Q/E 探头实施状态（2026-09-23）

> 任意代理可读；当前仅完成代码、EditMode 与双端构建。实机画面、命中和联机证据待按 Docs/07 取得本次授权后补齐。本文件不是实机验收结论。

## 已接入

- Q/E 探头输入：默认长按、切换模式、双键竞争、同帧双按回正、输入阻断后必须松开重按；键位追加至设置映射，模式和键位支持草稿预览、取消回滚、应用保存与账号偏好同步。
- 共享 `LeanProfile` / `PlayerLeanState`：0.25 m 眼点横移、20° 上身倾斜、12° 镜头倾斜、0.18 s 探出／0.14 s 回正；服务器与客户端同一模拟入口，头、眼、上身路径扫掠并检查终点重叠。探头时地面步态降至现有静步；跳跃、离地与输入冻结清态。
- `MovementCommand`、`MovementSnapshot`、`ObserverPose` 携带探头意图与实际幅度。服务器对旧输入有复位门禁，预测按探头偏差独立纠正；远端姿态与位置共用显示时钟。协议由 `fps-net-v11` 升到 `fps-net-v12`。
- Cinemachine 相机位置与侧倾层、FP 武器根偏移；TP 瞄准与探头由 `TPAimDriver` 单组件合成，Spine/Chest 以 60/40 分摊，Neck/Head 总反向补偿 8°；左手 IK 在其后执行。未重新求值的骨骼姿态不会逐帧累积。
- 受击代理拆为固定下身、可动上身及头部三节点，保留原中立几何；历史回溯记录各节点位姿。服务器射击历史按同一输入 tick 保存眼点、逻辑枪口、身体锚点。
- TP 投掷资源接入步枪/手枪 `start`、`pose`、`release`、`cancel` 片段，投掷阶段、类型、时钟与生命代际由权威状态同步；准备和释放阶段隐藏枪并显示手持物，左手扶枪 IK 退出。弹体与库存仍由 Gameplay 权威处理；受阻取消不扣库存。
