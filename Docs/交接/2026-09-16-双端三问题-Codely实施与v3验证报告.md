## 1. 本轮代码落地（对应审计 §6.2 / §6.3）

### M1 未确认批次与服务器缺口
- `PredictionBuffer.CollectUnacked` 改为"完整收集 → 排序 → 截断"（旧实现按 Dictionary 枚举凑满 max 就 break、之后才排序，删插后枚举顺序≠tick 序会漏最旧输入）。
- `ServerInputQueue` 缺口显式化：`SkippedTicks` / `LastDrainGap`（`Drain` 中检测），服务器 tick 处理器节流告警 `[Day3][Input] GAP`；`[MoveDiag]` 新增 `gaps=`。**语义已写明**：ACK = "已处理到该 tick"，缺口即"跳过并结算"、永不被模拟，由客户端预测纠偏吸收——不得当成"已模拟"。
- 新增 `PredictionBuffer.InvalidatePredictedAbove(tick)`：硬重基遇命令缺口时作废 (replayed, newest] 的陈旧预测快照（**保留命令**以便重传）。

### C1 渲染视角 yaw 逐帧
- 累积点每帧消费一次本地 look 输入到 `_viewYawDegrees`；tick 提交时用"实际写入权威根的角度增量"（`DeltaAngle`，含后坐补偿消耗）扣减；偏移只写视觉节点 `localRotation`（绕 Y 旋转不改变轴上 CameraPivot 位置、不改权威根与碰撞根）；上限 10°；冻结/死亡/重生/接管归零；开关 `MovementPredictionConfig.ViewYawInterpolationEnabled` 可 A/B。

### C2 多模拟步插值端点
- `RunOwnerPrediction` 内**每步**更新 `_interpFrom/_interpTo`，只保留最后一对（旧实现记整帧首尾 → 一帧多步时位置白落后、单步/多步交替变速）。

### C3 纠偏 vs 传送
- 新增 `CarryVisualAfterRebase`：普通权威重基保留"纠偏前视觉世界位姿"作残差，按 0.12s 时间常数衰减（立即生效避免那一帧跳变）；位移 > `RebaseVisualCarryMaxMeters=2.5m` 视为真传送 → 清视觉历史；重生/死亡走 `ResetOwnerVisualInterpolation`。

### M3 重基语义 / 诊断 / 取证
- `HardSnapTo` 带 `MovementRebaseKind`：Initial / HistoryMissing / Snap / Divergence / Overflow / DeathRespawn 全部计入 `diag.rebase`（旧实现只统计三类，`snaps=0` 会被误读为"零对位"）；死亡边界只计一次。
- **有意偏离审计字面要求并给出理由**：`_localTick` 仍取 `max(replayed, newest)` 而非审计建议的 `replayed`——回退会让后续 tick 命中缓冲里已有命令，`TryStore` 静默拒绝 → 该输入既不记录也不上传，形成静默空洞（比"假装模拟过"更难查）。改由 `InvalidatePredictedAbove` 消除陈旧对比这一真正问题。
- 新增前进回拉取证 `MovementPullbackTrace`（环形 96 条）：同 tick 记录输入 Move / 模拟前根位 / CC.Move 后根位 / SmoothCorrection xyz / HardSnap 前后根位 / 最终渲染位 / 水平前向，用 `dot(位移, 前向)` 区分前后，归因 MovePhase / AuthorityCorrection / RenderPhase，反向时节流导出 `[Pullback]`。
- 快照确定性：`MovementSnapshot` 增 `Grounded/GroundSpeed/CoyoteTimer/LandTimer/SprintIntent/RecoilDebt`；`Locomotor` 精确恢复（不再用 `|v|`/枚举推断，新增 `_groundedSampled`）；`WeaponRecoilState` 增 `CompensationDebt/RestoreCompensationDebt`（重放前恢复债务，避免二次消费）。→ **协议递增到 `fps-net-v3`，必须双端同批重建**。

### D1 远端动画状态源
- 删除 `PlayerNetworkAdapter.WireRemotePresentation` 反射死接线（`field.FieldType.IsInstanceOfType(remoteView)` 恒 false → 远端永远读本地不模拟的 Locomotor）。
- `TPAnimDriver` 新增 `remoteStateView` 字段 + `ResolveStateSource()`：远端替身启用 → `RemotePlayerStateView`（其底层 `NetworkLocomotionState` 的 getter 已按 本地/远端/离线 三分支给出正确值），否则本地 `PlayerStateView`；新增只读探针 `UsingRemoteSource`/`SourceLocomotionState`/`SourceGaitPhase`/`SourceMoveInput`。新增 `ITpLocomotionSource` 接口。

### D2 死亡姿态写者统一管理
- `NetworkCombatAuthority` 死亡表现改为按**显式谓词**收集全部姿态写者（`Animator` + 名字含 `Animancer/TPAnim/TPAim/TPLeftHand/FPRightHand/FPLeftHand/TwoBoneIKSolver`），记录 `(Behaviour, wasEnabled)` 精确还原；旧实现漏停 `TPAimDriver`/`TPLeftHandIK` → Animator 冻结后同一 pitch 逐帧叠加、持续扭曲并使贴地包围盒失效。
- `TPAimDriver`/`TPLeftHandIK` 各自加死亡闸门（死亡期间不再写骨骼，并清零累计状态：`ResetAccumulatedPose()` / `_currentWeight`）。

### D3 死亡状态单源
- `SyncDeathVisualWithState` 严格由 `_dead` SyncVar 驱动（`if (dead == _deathVisualActive) return;`），`ObserversDied/ObserversRespawned` 只触发同代再求值——去掉 `_deadStateSeen` 锁存，消除 RPC/SyncVar 先后到达造成的来回 Apply/Reset；`OnStopNetwork` 清理（池化/停止边界）。

### D4（部分）重生网络插值边界
- `ServerRespawn` 补全快照确定性字段；运行时置 `NetworkTransform._enableTeleport=true` 并调用 `Teleport()`（否则观察者沿旧插值历史从死亡点滑向出生点）。
