# Docs/20 全链路 UI 风格重做实施计划（注册 → 大厅 → 进入游戏）

> 状态：**已实现待用户实机验收**（2026-08-31）
> 前置文档：Docs/15（登录大厅商城全量实施）、Docs/19（配件与联网）

## 1. 目标与范围

将 Boot → 登录/注册 → Identity → 大厅（全部子页）→ 进入游戏 → 局内演示 HUD/暂停/结算 全链路 UI 从"代码拼色块原型"升级为 **LowPoly 风格化** 成品视觉（参考 Synty POLYGON 系列官方 UI + 主流 FPS 大厅布局惯例）。

**已拍板决策：**

| 项 | 决策 |
|---|---|
| 视觉风格 | LowPoly 风格化：明快配色、2px 粗描边、伪 3D 厚度按钮、圆角卡片 |
| 实现架构 | 代码生成 2.0（重写 ViewFactory 为设计系统，保留代码生成 uGUI 路线，EditMode 可测） |
| 美术素材 | AI 生成关键视觉：登录/大厅背景（generate_image 单图 + 程序化压暗）+ Logo 徽标；控件纯程序化 |
| 大厅导航 | 左侧纵向 NavRail（图标+文字，COD/Valorant 惯例） |
| Presenter | 全拆 Page Builder，公共契约（Initialize/Navigate/LobbyPage 枚举）不变 |
| 真 HUD | 不动 Presentation/HUD 十字准星系统（Day4 已实机验收），仅换肤大厅演示 HUD/暂停/结算页 |

## 2. 视觉规范

### 2.1 色板（UITheme 单一事实源）

| Token | 色值 | 用途 |
|---|---|---|
| BackgroundDeep | #141B26 | 页面底色（程序化兜底背景） |
| BackgroundPanel | #232F3F | 面板底 |
| CardSurface | #2E3D52 | 卡片面 |
| CardBorder | #141B26 | 2px 粗描边（深色压边） |
| AccentPrimary | #FFC93C | 阳光黄主强调（CTA/金币） |
| AccentSecondary | #6BCB77 | 草绿次强调（成功/已拥有） |
| AccentInfo | #4D96FF | 信息蓝（链接/次级按钮） |
| AccentDanger | #FF6B6B | 警示红（错误/退出/未拥有） |
| TextPrimary | #F5F7FA | 主文案 |
| TextMuted | #9AA7B8 | 次要文案 |
| ButtonShadow | #0D1117 | 按钮底部 4px 厚度层 |

- 文字/背景对比度 ≥ 4.5（EditMode 断言）
- AI 背景图一律叠加深色渐变罩（底部 60%→0% 透明）保证可读性

### 2.2 字体

- TMP 全文案；中文 fallback = Noto Sans SC（Assets/Codely/Fonts/）
- 标题：Bold 风格（TMP fontWeight + 1-2px 深色描边/下投影），不引入第三方商业字体
- 字号梯度：Hero 44 / PageTitle 36 / CardTitle 24 / Body 18 / Caption 14

### 2.3 组件规范（UIComponents）

- **StylizedButton**：圆角 10px + 2px 深色描边 + 底部 4px 厚度层（伪 3D）；hover 上浮 2px+提亮，press 缩 0.96（DOTween）
- **StylizedPanel/Card**：圆角 12px + 2px 描边 + 微渐变顶点色
- **StylizedInput**：聚焦时描边变 AccentPrimary + 外发光；错误时抖动
- **NavPill**：NavRail 条目，选中态左侧 4px 强调条 + 底色提亮
- **ProgressBar**：圆角槽 + 厚度层 + 斜纹填充（程序化）
- 图标：程序化几何图形（圆形/三角/矩形组合），不依赖外部图标库

### 2.4 动效（UIMotion，DOTween）

- 页面切换：0.25s 淡入 + 12px 上移（Ease.OutQuad）
- 按钮 press：0.96 缩放 0.08s；hover 提亮 0.12s
- 数字滚动：金币/XP 变化 0.5s 滚数
- 加载：三点弹跳 spinner

## 3. 架构（Scripts/UI/）

```
DesignSystem/
  UITheme.cs        色板/字号/间距/圆角/描边常量（静态只读）
  UIComponents.cs   StylizedButton/Panel/Input/NavPill/Card/Badge/ProgressBar
  UIMotion.cs       DOTween 动效封装（静态方法，空引用安全）
  UITypography.cs   TMP 字体资产绑定与默认样式
  UIArt.cs          AI 素材注册表（Sprite 加载 + 程序化兜底，离线可跑）
Pages/
  AuthPagesBuilder.cs      Login/Register/Identity
  LobbyShellBuilder.cs     NavRail/品牌区/状态栏壳
  LobbyHomeBuilder.cs      大厅首页（档案卡 + 进入战斗 CTA）
  CatalogPagesBuilder.cs   Armory/Shop/WeaponDetails
  MiscPagesBuilder.cs      Mission/Upgrades/Settings
  OverlayPagesBuilder.cs   演示 Hud/Pause/Results/Error/SessionExpired
LobbyPresenter.cs     保留 Initialize/Navigate 契约，页内渲染委派 Builder
```
