# 26 四天 56 小时项目收口与三 AI 分工计划

> 制定日期：2026-09-05（北京时间）  
> 适用分支：`codex/release-56h`  
> 正式方向：LPFP + Arena，LPW/Arena_LPWTest 仅作只读遗产  
> 目标：在最多 4 天、56 小时关键路径内，交付可演示、可重复验证的 Dedicated Server 多人 FPS 闭环。

## 0. 结论与完成口径

56 小时可以完成“局域网/固定公网节点上的 Demo 级完整闭环”，前提是冻结范围、优先解决独立权威服务器，并由 Codex 控制接口和集成。以下内容不纳入本轮完成口径：云端弹性编排、跨区域匹配、主机迁移、完整断线续局、商业级反作弊、全武器逐枪美术精修。

本轮完成必须同时满足：

1. Dedicated Server 独立启动，房主只是普通客户端；房主退出后，三人及以上对局继续。
2. 两人局任一人退出后由服务器结束比赛；三人及以上仅移除退出者。
3. 登录、房间、加入凭证、进场、战斗、退出、结算、回大厅形成闭环。
4. 客户端不能决定人数、胜负、生命、伤害、弹药、比分或结算结果。
5. ESC 菜单、设置、灵敏度、音量、键位及输入门控实际生效。
6. 正式 LPFP 武器完成身份、枪口、准心动态反馈和基本动画回归。
7. 后端测试、Unity EditMode、三客户端人工验收和构建冒烟均留有证据。

## 2. 三 AI 固定职责

### Codex：大脑、审计与集成负责人

- 唯一架构裁决者：冻结拓扑、协议、数据权威边界和验收口径。
- 每个工作包开始前给出文件白名单、接口和测试要求；结束后审查 diff。
- 负责创建集成提交、处理冲突、运行总门禁、更新风险表和下一轮提示词。
- 不与执行者同时编辑其所有权文件；除紧急集成修复外不承担大块编码。
- 任何扩范围、协议变化、场景结构变化必须先回到 Codex 复核。

### zcode：夜间独立模块执行者（23:00–次日 07:00）

- 独占后端控制面、房间 API、客户端房间 UI、设置/通行证及 LPFP 非网络表现收口。
- 每夜只接边界清晰且能在夜班内闭环的票据，开工即写增量交接。
- 不编辑 FishNet 核心文件、玩家网络 prefab 或 Arena 网络场景结构。
- 只在正式 Arena/LPFP 链工作，不得修改或扩展 LPW 实验链；遵守其 `AGENTS.md` 夜班、测试授权、点名暂存与 06:53 冻结规则。

### Codely：日间网络核心执行者

- 独占 Dedicated Server、FishNet 权威逻辑、比赛生命周期与网络测试。
- 不编辑后端房间业务实现、Lobby/设置/通行证及武器表现文件；跨端需求仅消费 Codex 冻结的 DTO。
- 每个工作包单独提交；提交前提供编译、测试与行为证据。

## 4. 56 小时关键路径

这里的 56 小时是从开工到交付的关键路径预算。Codely 与 zcode 可在边界清晰时并行，节省出来的时间进入回归缓冲，不用于扩需求。

### 第 1 天：基线冻结与独立服务器骨架（0–14h）

**Codex，2h**

- 冻结 Dedicated Server 方案：无图形 Unity Server Build + FishNet ServerManager；房间中的 host 改为房间管理员，不再拥有服务器进程。
- 冻结 `RoomRuntimeState`、`JoinTicket`、`MatchEndReason`、`PlayerLeft` 契约。
- 审核并建立实验路径阻断清单。

**zcode，4h（23:00–次日 07:00 窗口内）**

- 实现服务器实例注册、心跳、过期清理、房间绑定和一次性/短期加入票据。
- 房间管理员退出只更新成员与管理员归属，不删除运行中的多人房间。
- 添加并发、幂等、过期票据和管理员退出测试。

**Codely，8h**

- 增加 Dedicated Server 启动入口与 Server Build 配置。
- 服务器无需本地玩家即可加载 Arena、启动 FishNet、维护比赛状态。
- 客户端通过 endpoint + ticket 连接；移除“创建房间者必须 StartHost”的正式依赖。
- 交付 headless 启动日志、两个客户端连接证据和编译/EditMode 结果。

**Gate D1**：独立服务器能启动并接受两个客户端；任何客户端退出都不会杀死服务器进程。

### 第 2 天：房间—服务器闭环与退出语义（14–28h）

**Codex，2h**

- 复核 Day 1 diff、契约漂移和安全边界。
- 针对已知离开者胜负双重取反风险补测试要求。

**zcode，4h（夜班）**

- Lobby 创建/列表/加入/离开接入实例状态与 join ticket。
- 明确显示服务器启动中、可加入、满员、比赛中、已结束和连接失败。
- 管理员退出时选定新管理员，仅为 UI/房间管理权转移，不触碰游戏服务器权威。

**Codely，8h**

- 重做退出链：2 人局退出即服务器终局；大于 2 人只 despawn/kick 离开者。
- 主动退出、断线、超时统一走服务器入口，并保证一次性。
- 客户端本地只请求退出，不提交人数/胜负/结算。
- 为 2、3、4 人矩阵补纯逻辑及网络生命周期测试。

**Gate D2**：三客户端中“创建房间者”退出，余下两端比赛计时、比分和战斗继续；服务器进程不退出。

### 第 3 天：权威收口与独立模块并发（28–42h）

**Codex，2h**

- 做一次服务器权威审计：移动、射击、弹药、伤害、死亡、复活、比分、时间、结算。

**zcode，4h（夜班）**

- 收口 Battle Pass/商城/配装的数据读取与错误态，仅修阻塞闭环的问题。
- 后端全量测试，修复正式 LPFP 商品种子与断言漂移。

**Codely，8h**

- 服务器验证射速、弹药、换弹、伤害、死亡、复活和比分；拒绝越权 RPC。
- 移动至少实现服务器边界验证与异常位移纠正；预测/回滚若影响工期则不扩展。
- 结算只由服务器最终状态产生，并使用稳定 playerId 幂等提交。

**Gate D3**：伪造伤害/比分/人数/结算请求无效；正常玩家流程不出现明显回弹或重复结算。

**Codely，6h**

## 5. 验收矩阵

| 场景 | 必须结果 |
|---|---|
| Dedicated Server 空载启动 | 无本地 Player，Arena 正常运行并注册心跳 |
| 2 人任一方退出 | 一次 Ended；离开者负、留下者胜；双方不重复结算 |
| 3 人普通成员退出 | 仅该成员离场，比分/计时/Phase 保持 |
| 3 人房间创建者退出 | 游戏继续；必要时房间管理员转移 |
| 客户端断线/强杀 | 与主动退出相同的服务器策略 |
| 客户端伪造伤害/比分/人数 | 被忽略或拒绝，服务器状态不受污染 |
| ESC 菜单 | 不暂停网络世界；本地移动/射击输入封锁；恢复无粘键 |
| 设置 | 应用持久化、取消回滚、音量 0 真静音、灵敏度仅乘一次 |
| 正式 LPFP 武器 | 火光来自正确 Muzzle；切枪无残影；ADS/换弹/开火可用 |
| 动态准心 | 静止收拢，移动/冲刺/跳跃扩大，落地停止后平滑恢复 |

## 6. 提交与质量门禁

每个工作包必须：

1. 从 `codex/release-56h` 最新集成点开始，禁止从原脏分支整体复制。
2. 只修改票据白名单文件，逐文件暂存；不得 `git add .`。
3. 提交前运行 `git diff --check`、相关测试，并搜索新增差异中的 `LPW|Arena_LPWTest|weapon.lpw`。
4. 不提交 `Library/`、`Temp/`、`Logs/`、`UserSettings/`、`.zcode/`、`out_test/`、录屏、截图和生成报告缓存。
5. 执行者只提交自己的工作包，不自行合并；Codex 审核后集成。
6. 任何失败必须区分“本轮回归”与“既有失败”，不得以全量计数掩盖新增失败。

## 7. 砍项顺序与停止线

若进度落后，只能按以下顺序砍项，不能牺牲 Dedicated Server 或权威正确性：

1. 美术润色、额外动效和非阻塞 UI 动画。
2. 低优先级通行证/商城体验增强。
3. 高级移动预测、延迟补偿和断线续局。
4. 非核心武器的逐枪精细姿态调优。

不可砍：房主退出继续、2 人退出终局、身份/结算幂等、基本作弊边界、ESC 输入安全、三端验收和可复现构建。

在 T+28h 若 Gate D2 未通过，冻结所有 UI/武器增强，zcode 仅负责后端接口、测试夹具和联调支持，Codely继续集中处理网络主链；在 T+42h 若 Gate D3 未通过，取消全部体验增强，只保留权威链与发布门禁。

## 9. 风险判断

- **最高风险**：从 client-hosted 切换 Dedicated Server 涉及启动、场景、身份和连接链，必须先于其他功能。
- **高风险**：原工作区正式改动与实验改动混合，整文件搬运会重新污染发布分支。
- **高风险**：后端房间管理员、游戏服务器拥有者和比赛权威是三个不同概念，必须保持解耦。
- **中风险**：三客户端 PlayMode 验收依赖人工/多实例环境，需每天预留证据窗口，不能拖到最后一小时。
- **工期判断**：严格按本计划的 Demo 完成口径，56 小时可行但缓冲有限；若要求生产云部署、完整反作弊或全武器精修，则不可在同一时限承诺。
