# 左手拔环与双手配合修正（2026-09-29）

## 范围

保留上轮右手上臂领动、前臂跟随。围绕左手接近、抓取、绷紧、分离、带环收回完善表现。没有修改 Gameplay、相机和按键等待逻辑，没有构建发行包或跑联机实机测试。

## 检查结果

- 左手具有 `finger_01_L/02/03`（食指）、`thumb_01_L/02/03`（拇指）和 `middle_finger_01_L/02/03`（其余手指组）。可以分开食指、拇指和其他手指的手型，不能假设有五条独立手指链。
- Frag、Flash、Smoke 的原模型都是单 MeshFilter、单材质网格，原来没有可脱离拉环 Transform。按重合位置焊接后检查连通分量，三者各有独立的 256 顶点环体及 48 顶点销轴，可以在自有资产中无损拆分。拓扑证据：`Logs/PinPull0929/Throwable_{Frag,Flash,Smoke}-mesh.json`。
- 旧左手共用近似握拳曲线，掌心朝向固定；拉开后不存在随手退出的独立拉环。只改手臂位置无法解决。

## 实施

1. 准备阶段先张开食指和拇指接近，后形成抓取；其他手指保持较放松的弯曲。抓取姿态下食指接触点与拇指尖约相距 2.6 毫米。
2. 投掷视觉开始后保留短促绷紧段，右手有 8 毫米侧向、4 毫米向后的反向支撑。视觉拉环在 0.12 秒分离，然后左手沿拉开的方向收回并转出掌心。该动作没有新增输入等待，不改变 0.35 秒投掷物出手或 1.15 秒动作结束。
3. 环体和销轴复制拆分为自有第一人称部件，世界模型和供应商 FBX 不变。取环下沿作为抓点，使环孔露在指尖上方；脱离后随左手食指末节移动。使用自有金属材质提高环体辨识度。
4. 新增 `FPThrowablePinView`，由 `FPWeaponAnimator.LateUpdate` 在动画图之后显式驱动：接触阶段仅校准左臂到各模型抓点，保留片段的手型和掌心旋转；分离后停止接触校准，环转交食指节点。它不写右臂，也不驱动任何投掷、物理或联网事件。
5. 持有物出手隐藏时，已拆下的环继续留在左手。取消、死亡、切枪和销毁走同一清理入口，避免留下悬空环或跨次投掷复用。
6. 动画生成器的完整 Build 同时重建抓环校准资产，避免以后改手型却遗留旧的环偏移。

运行时的兼容 LPW 持枪 IK 仍由原有投掷让位分支退出。新接触校准只负责本动作的左手接点，不覆盖上轮右臂发力。
