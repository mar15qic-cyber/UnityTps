# PreviewV1 r3：枪口特效与正手投掷修复

状态：本次目标内的枪口曳光与右手正手投掷修复已完成；定向检查、实机复核、正式双端构建及朋友客户端 ZIP 校验通过。

本次按用户后续明确授权开展多轮截图验证，覆盖黄色枪口特效、消音器出口、投掷动作及衔接。之前“一轮”限制已被本次多轮授权替代。保留旧 r2 文件和失败证据，不作 git 提交。

## 根因与最终修复

**黄色曳光偏离枪口**：WeaponView.Awake 创建世界层的曳光对象后，FPWeaponRig 创建视图时递归设置第一人称层，连同曳光一起改到了层 9。曳光坐标为世界相机计算，却由第一人称相机渲染，产生屏幕偏移。此前探针只比较世界投影，未检查实际渲染图层，因而出现数值近零但截图仍错。WeaponView.UpdateTracerGeometry 现在在更新每条曳光时恢复世界层，出口仍使用当前裸枪/消音器的真实出口。原 r2 诊断 114 个曳光帧全部图层错误；修复后的完整射击矩阵为 0。

**投掷动作方向错误**：旧片段及本会话首版可见性调整保留了左手掌心朝上的前送动作。用户指出反手问题后，已废弃该动作方案。FirstPersonThrowClipBuilder 生成项目自有右手正手动画：握持→右肩侧上举蓄力→向前伸臂翻掌→松指→收手；持物挂点改为 hand_R。烘焙时保持骨长，原始第三方 FBX 不改。资源文件名仍为 FP_Throwable_VisibleArc.anim，内部片段名为 FP_Throwable_Overhand。

**瞄准转投掷时枪身遮挡**：补充实机衔接截图发现狙击枪从镜内切手雷后，枪身仍显示。FPWeaponAnimator 原来直接写 Renderer.enabled，且跳过当时已经被镜内遮罩隐藏的 Renderer；ScopeOverlay 释放时又按作者基线恢复枪身。现在投掷隐藏与死亡、镜内隐藏交给同一可见性管理器合成，手臂保持显示，枪身和配件保持隐藏，结束后恢复作者基线。激光持续写者也服从投掷隐藏状态。

**巨大世界手雷的另一条链**：坡面复现证明世界投掷物尺寸始终约 0.08m，撞坡反弹回镜头时深度经过 1.62m、0.74m、-0.0036m，造成近景放大。不能用缩小模型或隐藏物理投掷物掩盖。该解释与正手动画修复分别成立。

本机 API、专服、两个客户端运行在隔离端口 5180/5181/27770。覆盖视觉和状态衔接，不是朋友异地公网、各种显卡或长时间压力测试。测试用例用局部诊断指令切枪、装配、补弹和定位；没有修改枪口坐标或动画来制造通过截图。
