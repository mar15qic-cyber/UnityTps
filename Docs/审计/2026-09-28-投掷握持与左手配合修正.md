# 投掷握持与左手配合修正（2026-09-28）

## 用户反馈与范围

检查用户 `20.53.33.21.mp4` 的前 8 秒，并对照 `21.11.40.22.mp4`（全长约 4.64 秒）的 CF 投掷参考。保留右手正手投掷方向，修正虎口、腕骨和弹体的相对姿态，补充左手参与。本轮没有重新构建客户端/服务端，没有执行联机实机测试；PreviewV1-r3 目录和朋友 ZIP 未更新。

## 根因与修正

- 上一轮由 Codex 编写的 `FirstPersonThrowClipBuilder` 把右手世界旋转设为接近单位旋转，而持有模型仍用单位局部旋转。弹体 Y 轴沿手指方向，未对齐骨架中朝虎口的 -Z 轴。拇指还继承了 M4 Idle 姿态。
- `FPWeaponAnimator` 现在明确设置弹体局部旋转，并同步旋转模型包围盒中心补偿；右腕、拇指与手指的握持姿态一起重新烘焙。手雷、闪光弹、烟雾弹仍使用各自原模型及尺寸。
- 旧生成器把左腕固定在画面外。新增 `FP_Throwable_Prepare.anim`：按住投掷输入时左手靠近，取消按住时平滑返回；投掷片段中左手接触、分开、伴随和收回。
- 短按不应因 0.12 秒过渡跳过左手接触：投掷开头保留 0.10 秒接触段，过渡上限 0.08 秒。保持目录中的 0.35 秒出手和 1.15 秒动作结束时序。
- 45 个目录内第一人称预制体均绑定准备片段；16 把原生枪械受参数化测试覆盖。未修改供应商 FBX，未从 CF 提取模型或动画；CF 仅作为动作组织参考。
