# 拿出动画左手残影修正（2026-09-29）

用户指出拿出预览开头出现空左手；要求拿出只由右手参与。本轮修正运行时混合，没有重做已认可的右手拿出、拔环或投掷片段，没有构建双端。

## 原因与责任

截图对应 `Logs/ThrowableDraw0929/cycle/frame-000.png`。共用拿出片段本身将左手收在屏幕外，但 FPWeaponAnimator 用 0.06 秒全身交叉混合从步枪待机进入拿出；第零帧的旧托枪左手仍然完全保留，而枪械渲染已隐藏，形成空手悬在画面内的表现。上轮测试没有用真正的步枪待机作为起始姿势检查第零帧，漏掉了此问题。

新增测试分别从步枪待机、双手抓环姿势切入拿出，在修复前均于第零帧失败。记录：`Logs/ThrowableDrawLeftFix0929/before-tests.txt`。

## 修正

`FPWeaponAnimator.cs` 新增仅覆盖左臂路径的拿出姿势层，从第零帧立即使用 Draw 的收起姿势。右臂仍走原有主层混合。进入准备或投掷时该层退出，左手重新参与拔环；取消/禁用时清零，销毁时释放临时 AvatarMask。

这不是隐藏整个手臂 Renderer，也不是在拔环过程中永久锁住左手。没有改玩法时序、准备输入、出手事件或镜头。
