# 拔环双手关键姿势稿：待用户确认（2026-09-29）

本轮按用户要求先提交三个静态关键姿势。只生成独立 Unity 预览及可复现的脚本，没有覆盖正式动画、预制体、运行时代码或构建包。尚未细调过渡、速度、短按混合或退出全程，不以静帧代替动态验收。

## 检查与姿势决策

- 现有动画准备阶段右手保持 ReadyPalm，左臂主要由末端接触校准追到拉环；分离后左掌另有朝内转向。此次稿件重排肩、肘、腕与雷体的共同关系。
- 左手仍使用已有食指、拇指、其余三指组骨骼，没有增加不存在的独立手指。食指与拇指保留携环手型，另外三指组弯曲收拢。
- 原 Frag 网格的销轴沿模型 X 轴，环在正 X 一侧。原握持基准将该方向指向右侧，与左手拉出方向相反。预览将模型相对右手的握持基准绕雷体纵轴重新索引 180°，使环位于左侧；这是初始握持基准修正，不是要播放一次 180° 翻雷。正式落地时须同步复核右手握持和保险柄接触。
- 在该基准上，右手在“即将接触”已倾转，接触到拔开继续适度倾转（预览参数 22°→30°），不等拔完后才开始转雷。上臂、前臂也重新求解到该准备姿势，不独立拧手掌来硬够。
- 左肩适度前送、肘外展，以手背更容易被看见、掌面偏下的姿态接近。三个姿势的掌面朝向有小幅变化；不是全程固定掌面角度。
- 第二姿势指尖接触环下沿；第三姿势先维持接触相对变换将环转交食指，然后沿销轴向左下拉出 6 cm。第三姿势只代表刚分离，不是新增一个下甩动作，也不预设此处停顿。
