## 枪口：16 把全部覆盖

运行时统一使用 `MuzzleExit`：本地曳光、火焰、点光源共用出口；第三人称武器也读取对应出口。正式消音器使用项目内 `Silencer_Visual.prefab`，出口标定在模型 -Z 端口，保留原资源包只读。

逐枪检查实际网格和蒙皮权重后修复了五处具体问题：

| 枪械 | 原因 | 修复 |
|---|---|---|
| M4 | 斜切枪口下方齿尖被当作孔中心，约低 7.3mm | 完整圆形截面定轴，前端定深度 |
| SMG04 | 同类斜切端面，约低 8.1mm | 用完整后截面定轴 |
| Shotgun01 | 1.5mm 薄片混入前准星，偏移约 2.46mm | 只取枪管前端圆环 |
| Sniper01 | 出口挂在 `lid_2`，枪管顶点实际属于 `weapon` | 重新绑定真实枪管骨骼 |
| Sniper02 | 出口挂在 `lid_2`，枪管顶点实际属于 `barrel` | 重新绑定真实枪管骨骼 |

另外 11 把同样校准、验证和写入出口。FP/TP 配件安装点与裸枪口同步。旧校准入口尊重已标定的出口，避免再次用最前端薄片覆盖结果。三把原生狙击枪当前目录没有 Muzzle 装配槽，验证其裸枪；其余 13 把覆盖正式消音器。

验证不是只比较保存的坐标：`PreviewVisualRegressionTests` 固定枪管截面顶点编号，采样 Idle/AimIdle/Fire/AimFire 六个时刻，逐帧 BakeMesh 后与出口对照；同时核对骨骼权重与父节点。16×4×6＝384 个裸枪姿态，误差门限 0.5mm。另有 384 个正式 LineRenderer 起点的跨相机投影检查，1920×1080 下门限 0.25px，并验证终点不变。正式消音器遍历支持的武器和目录条目，检查上述四种姿态与六个时刻、火焰父节点及卸载恢复。

## 投掷：移除屏幕钉住整套手臂的补丁

- 删除根据手雷当前位置计算并叠加整个 FP 根位移的逻辑，改用原资源相机与骨架的固定参考关系。
- 所有武器共用同一套投掷手臂动作，避免手枪动画末尾的低持枪姿态把手雷压出屏幕。
- 准备阶段使用稳定的收尾持握姿态；投掷播放完整原动画，不再把 35% 片段强制压缩到 0.15 秒。
- 释放延迟恢复为原资源的 0.35 秒，动作窗口为 1.15 秒，覆盖 1.133 秒动画与收尾；FP 左右手持枪 IK 在投掷期间让出控制权。
- 全部 16 把的持握物可见性、动画长度覆盖检查通过。编辑态烘焙网格预览已保留到 `Logs/VisualFix0928/baked-*.png`，准备姿态为 `baked-1.00.png`。

## 地图：防止 Dedicated Server 构建污染客户端内容

`HotUpdateBundleBuild` 使用 `BuildAssetBundlesParameters.subtarget = Player`，强制重建并检查源材质；私有地图构建复用该入口并恢复原子目标设置。

发布前直接解析实际 UnityFS 文件的 Material→Shader 引用，不能用源 `.mat` 正常、哈希相等或下载成功替代。`Publish-HotUpdate.ps1` 与 `Package-PreviewV1.ps1` 都会阻止空 Shader 引用的 bundle；打包默认选择最新暂存版本，不再硬编码损坏的 v16。

旧 PreviewV1/v16 NightRelay 包被验证器明确拒绝：26 个材质的 Shader 引用全部为空。最终新构建结果如下，构建前后编辑器均保持 Server 子目标，地图构建显式使用 Player：

| 地图 | 材质数 | Shader 数 | 空 Shader 引用 | SHA256 |
|---|---:|---:|---:|---|
| NightRelay | 26 | 7 | 0 | `5949fb42f75d6a6cdce708f1ae8a8f334e94bd1957bd06db3de8c576968b6eea` |
| TrainingYard | 28 | 8 | 0 | `91df638f84b2602963694965d6e1dee6d3297ee160bfbef2e51be0c383ba5169` |

`Publish-HotUpdate.ps1` 不带 Deploy 执行成功，生成 v17 的普通与地图清单。旧 v16、现有 API 内容、客户端/服务器 EXE 和分发 ZIP 均未覆盖。此暂存包不等同于完整修复后的双端测试包。
