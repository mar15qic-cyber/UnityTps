# 投掷上臂领动修正与对比

## 范围与结论

保留现有准备、左手配合、右手上手投掷、松手和恢复流程。修改仅涉及右臂视觉动画的生成与烘焙，以及诊断和回归检查。没有修改镜头、玩法时序、权威投掷、初速度/方向、冷却或切枪限制；没有构建发行包或执行联机实机测试。

## 修改前检查

实际层级：`Armature/arm_R/lower_arm_R/hand_R`，没有独立锁骨。上臂长度约 0.2301 米，前臂长度约 0.2384 米。`arm_R` 是肩部枢轴。原片段有 189 条位置/四元数曲线。

旧生成器固定肩位置和肘极向量，以腕部目标做双骨 IK；各段使用相同 SmoothStep，肩肘腕没有独立的发力时间关系。采样中肩位置完全不动，上臂和前臂的主要方向变化峰值均约 0.325 秒。此外逐帧 AddKey 的零切线会让慢放在每个采样点反复减速。

运行时所有权检查：

- 16 个原生武器预制体均未挂手部 IK、RigBuilder 或 Constraint。实例来源为 `FPWeaponRig.GetOrCreateView`，没有附加此类约束。
- `FPWeaponAnimator` 在准备和投掷期间使用专用片段，Update 提前返回；准备时清除手臂开火反馈层，投掷开始也释放该层。Root Motion 关闭。
- `FPWeaponMotion` 投掷分支使用固定相机相对视图框架，跳过持枪 sway/bob/ADS 对位。
- 兼容 LPW 视图上的左右手 IK 具有投掷让位分支；`LPWGunPoseDriver` 写的是隐藏的枪械分支，不是手臂。
- 用 M4、Sniper03、LPW Rifle01 的实际 Animancer 图，在独立预制体场景中按 60 Hz 手动步进，并调用兼容视图的 IK LateUpdate。0.12 秒后与片段姿态的最大位置差小于 0.00000027 米，旋转差 0 度；IK 位置改写为 0。该检查不是客户端联机实测。

证据位于 `Logs/ThrowKinetics0928/before/skeleton-curves.json`、`native-components.json`、`runtime-ownership.json`。

## 视觉修改

`FirstPersonThrowClipBuilder.PoseThrowingArm` 分别控制肩枢轴的位置、上臂方向、前臂方向和手掌姿态，按真实骨长进行逐级旋转，不再由腕部目标反推整条右臂。

肩部先少量后收，再向前内侧送出；右腕收向右后上方。上臂先把肘部向前送，前臂仍短暂折叠，然后在出手附近加速展开。三条轨迹重叠发生。位置和方向使用连续切线插值，右臂烘焙曲线补充平滑切线，出手后继续向前随动再恢复。

原先左手、准备片段和松指时刻保留。模型骨长不变，没有加入镜头震动或更改视图 FOV。

60 Hz 骨骼采样用于辅助判断（峰值时刻分辨率受采样率限制，不是视觉质量评分）：

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 肩位移 | 固定 | 参与后收与前送 |
| 上臂方向变化主要峰值 | 约 0.325 秒 | 约 0.258 秒 |
| 前臂方向变化主要峰值 | 约 0.325 秒 | 约 0.342 秒 |
| 腕部速度主要峰值 | 约 0.292 秒 | 约 0.342 秒 |
| 游戏出手时刻 | 0.350 秒 | 0.350 秒 |
| 游戏动作结束 | 1.150 秒 | 1.150 秒 |

证据：`kinetic-metrics.json`、`before/front/joints.json`、`after/front/joints.json`。
