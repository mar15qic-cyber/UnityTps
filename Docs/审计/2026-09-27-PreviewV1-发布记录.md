## 本地日志

- 客户端启动助手为每次运行创建 `%LOCALAPPDATA%\UnityFps\PreviewV1\Logs\<runId>\`，保留 `client.log` 及 `Telemetry\*.jsonl`。
- 主机每次启动创建 `HostState\logs\<时间-随机编号>\`，保留 API 输出/错误、逐地图 Unity 日志、逐地图 Telemetry。
- 双端通过编译定义默认开启采集；记录 UTC、releaseId、协议、角色、进程、sessionId、runId、matchId、场景和连接事件。
- 每秒记录收发包数/字节数、RTT、传输层丢失计数、FPS/平均及最大帧耗时；服务端另记逐连接统计。保留已有射击、命中、伤害、拒绝原因、tick、插值缓冲及位置纠正事件。
- 记录按 64 MiB 分段、约每秒刷新，正常退出关闭文件。硬退出/掉电仍可能丢失最后缓冲；日志不自动清理。
- 导出脚本递归读取并保留全部 59 个结构化字段，可共享读取活动文件，跳过未写完的最后一行。导出不包含原始 Unity/API 日志，也不自动上传。
- LiteNetLib 丢失计数不等同独立抓包的全链路丢包率；统计不可用时标注 `statisticsAvailable=false`。不记录网络载荷，不判断 ZeroTier 中继/直连。详见主机说明中的统计口径。
