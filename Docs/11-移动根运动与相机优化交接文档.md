## 1. 本次交接范围

1. 上一轮“根运动移动链路重构”的全部落地内容。

## 2. 当前权威链路

```text
InputReader
    ↓ MovementCommand（Move / Sprint / Jump / YawDelta / Tick）
Locomotor
    ├─ RootMotionProfile 计算确定性 XZ 位移与 GaitPhase
    ├─ CharacterController.Move
    ├─ Player 根节点 Yaw（只消费输入 YawDelta）
    └─ MovementSnapshot（未来网络校正入口）
            ↓
PlayerStateView（只读状态聚合）
            ↓
TPAnimDriver（TP Animator 唯一写者）
```

`Animator.applyRootMotion` 保持关闭。动画根位移由烘焙后的 `RootMotionProfile` 驱动，服务器/预测端不依赖运行时 Animator。

## 4. 本轮相机晃动优化

### 问题链路

跑步时原链路为：

```text
RootMotionProfile.RootQ
    → Locomotor 每帧直接 transform.Rotate(rootYaw)
    → Player 根节点周期性左右扭转
    → CameraPivot / Main Camera 是 Player 子节点
    → 第一人称视角继承完整步态扭转
```

Profile 中的 `RootQ` 仍是有效素材数据，但它包含角色步态周期内的往复扭转，不等同于 FPS 玩家真实的瞄准朝向。直接写入 Player 根节点会把这段步态摆动放大到相机上。

### 当前修复

在 `Locomotor` 增加了两个序列化参数：

- `rootMotionYawWeight = 0`：默认不把步态 RootQ 写入 FPS Player 根节点。
- `maxRootMotionYawStep = 0.35`：未来启用 RootQ 时限制单帧旋转上限。

因此当前 FPS 身体 Yaw 只由 `MovementCommand.YawDelta` 驱动；Profile 的 Yaw 曲线仍保留，可供后续第三人称视觉、非 FPS 相机或网络表现使用。

已同步写入：

- [Locomotor.cs](../Assets/_Project/Scripts/Gameplay/Movement/Locomotor.cs)
- [Player_Day2_Rebuilt.prefab](../Assets/_Project/Prefabs/Player/Player_Day2_Rebuilt.prefab)

`FPMouseLook` 未修改，仍只负责相机 Pitch；本轮没有引入第二个相机写者。

## 5. 网络与扩展边界

本轮没有实现 FishNet 网络代码，接口边界已保留：

- 服务器使用 `RootMotionProfile + MovementCommand`，不加载 Animator。
- Owner 预测端调用同一个 `Simulate`。
- Remote Proxy 不读取本地输入，也不应用 Animator 根位移。
- 网络适配层应只调用 `ApplyAuthoritativeSnapshot`，禁止直接写 Player Transform、调用 Animator 或同步动画状态。
- `ProfileVersionHash` 可用于后续客户端/服务器 Profile 握手校验。

未来增加下蹲、滑铲等移动时，建议扩展 Gameplay 语义（例如 `Stance` 或独立 Gameplay 事件），再由 `PlayerStateView` 提供只读状态给 `TPAnimDriver`；不要让动画脚本反向修改移动状态。

## 6. 用户实机验收建议

请由用户在 Unity 实机中验证：

1. Sprint 前进时镜头不再出现明显周期性左右摆动。
2. W/S、A/D 快速交替仍保持后按键优先和即时响应。
3. W→D→S→A 循环时速度与步态相位连续。
4. 斜向移动速度不超过直线 Walk 速度。
5. Jump/Air/Land 不被落地动画阻塞。
6. 移动中射击、换弹、换枪时 Layer0 腿部移动继续工作。
7. Scene View 与 Game View 中 Player 根节点、胶囊和 TP 模型没有不同频率的跳变。

若仍感觉有轻微晃动，下一步应先确认来源是相机 Pitch、武器视图摆动还是显示设备/帧率，而不是直接重新打开 `rootMotionYawWeight`。当前建议保持 `0`，待第三人称表现需求明确后再单独调节。
